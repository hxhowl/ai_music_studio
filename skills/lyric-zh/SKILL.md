# 中文歌词创作

## 铁律

1. **结构标签一律英文**，用 Suno 通用格式。标签内不写中文。
2. 歌词是**唱**的，不是读的。每写完一段，默念一遍，拗口就重写。
3. 押韵服务于情绪，不为押韵造废句。宁可破韵，不要写"我的心/你的人"这种填充。

---

## 一、结构标签库（Suno 通用）

| 标签 | 含义 | 常用度 |
| --- | --- | --- |
| `[Intro]` | 引子 | ★★★ |
| `[Verse]` / `[Verse 1]` | 主歌 | ★★★ |
| `[Pre-Chorus]` | 预副歌，情绪爬升 | ★★★ |
| `[Chorus]` | 副歌，记忆点 | ★★★ |
| `[Post-Chorus]` | 副歌尾缀 | ★★ |
| `[Bridge]` | 桥段，转折/升华 | ★★★ |
| `[Instrumental Break]` | 纯器乐间奏 | ★★ |
| `[Guitar Solo]` / `[Solo]` | 独奏段 | ★ |
| `[Hook]` / `[Refrain]` | 反复句 | ★★ |
| `[Breakdown]` / `[Drop]` | 电子乐段落 | ★ |
| `[Outro]` | 尾奏 | ★★★ |
| `[End]` | 结束标记 | ★ |

**元标签**（写在歌词开头或段落内）：
- `[Style: ...]` — 内联风格指示
- `[Exclude: ...]` — 排除项
- 和声：`[harmony]`、`[background vocals]`、`[backing vocals]`
- 演唱指示：`[whisper]`、`[falsetto]`、`[rap]`、`[spoken]`、`[chant]`

## 二、段落模板（按情绪需求选）

| 模板 | 结构 | 适用 |
| --- | --- | --- |
| **紧凑流行** | Intro - V1 - PC - C - V2 - PC - C - B - C - Outro | 主流流行，记忆点强 |
| **叙事民谣** | V1 - V2 - C - V3 - C - B - C - Outro | 有故事线，重主歌 |
| **情绪递进** | Intro - V1 - C - V2 - C - B - C - C - Outro | 副歌重复堆叠推向高潮 |
| **短平快**（短视频/卡点） | Intro - V - PC - C - C - Outro | 60–90 秒 |
| **说唱主导** | Intro - V1(rap) - C - V2(rap) - C - B - C - Outro | 主歌押双押/三押 |

选完要向用户说明**为什么选这套**。

## 三、十三辙押韵体系

中文歌词押韵以**十三辙**为准（详见 `references/rhyme-zh.md` 完整韵字表）。

| 辙名 | 韵母 | 情绪倾向 | 例字 |
| --- | --- | --- | --- |
| 发花 | a ia ua | 明亮、开阔 | 花 家 话 下 沙 芽 霞 |
| 梭波 | o e uo | 沉稳、叙述 | 河 火 我 说 破 过 朵 |
| 乜斜 | ie üe | 婉转、清冷 | 月 雪 夜 谢 别 街 蝶 |
| 一七 | i ü er | 细腻、私密、易密韵 | 期 你 意 里 雨 去 句 |
| 姑苏 | u | 低沉、呜咽 | 路 湖 树 苦 雾 孤 渡 |
| 怀来 | ai uai | 舒展、叹息 | 来 开 海 爱 外 待 快 |
| 灰堆 | ei ui | 柔婉、回落 | 悲 飞 水 泪 回 灰 醉 |
| 遥条 | ao iao | 悠远、飘逸 | 高 老 笑 道 草 桥 照 |
| 由求 | ou iu | 忧郁、绵长 | 愁 秋 留 手 头 酒 旧 |
| 言前 | an ian uan | 开阔、舒展、最常用 | 前 天 年 面 见 远 山 |
| 人辰 | en in un | 深沉、内敛 | 心 深 真 门 春 云 沉 |
| 江阳 | ang iang uang | 昂扬、宏大 | 光 长 方 上 乡 唱 望 |
| 中东 | eng ing ong | 浑厚、共鸣强 | 风 梦 中 空 声 影 情 |

### 选韵原则

- **开口度配情绪**：激昂用江阳/言前/发花（开口大）；低回用一七/姑苏/由求（开口小）
- **副歌固定一韵**，主歌可换韵制造对比
- **避免通押过头**：言前与人辰（-an / -en）可通押但慎用，容易糊
- **"一七辙"最易也最险**：字多好押，但容易写得绵软无骨
- **仄声韵**（三四声）比平声更有推进力和颗粒感，说唱和摇滚常用

### 韵脚位置

- **句尾韵**（默认）：每句/隔句末字同辙
- **句中韵**：句中顿挫处押，增加密度（说唱常用）
- **双押/三押**：末尾连续 2–3 字同韵（说唱）
- **转韵**：段落切换时换辙，标记情绪转折

## 四、字数与节奏规范

| 段落 | 单句字数 | 句数 | 说明 |
| --- | --- | --- | --- |
| Verse | 7–11 字 | 4–8 句 | 句长稳定，叙事 |
| Pre-Chorus | 5–8 字 | 2–4 句 | 短句加速，制造爬升 |
| Chorus | 7–12 字 | 4–6 句 | 句首放 hook，可略长 |
| Bridge | 6–10 字 | 2–4 句 | 常换韵、换视角 |
| Outro | 3–7 字 | 2–4 句 | 渐短，收束 |

**对齐规则**：同一段落内，对应句的字数差控制在 ±2 字以内。差太多唱不了。

## 五、写作流程

```
① 提炼立意（一句话，具体到场景，不是抽象情绪词）
② 选结构模板
③ 选韵辙（副歌定死，主歌可选另一辙）
④ 调 lyric-imagery-rhyme 取意象词组与押韵候选字
⑤ 写主歌（铺陈，给画面，不抒情）
⑥ 写预副歌（短句，情绪爬升）
⑦ 写副歌（hook 句首，重复密度高，字面固定）
⑧ 写桥段（换视角/换韵，说一句最真心的话）
⑨ 写尾奏（渐弱，留白）
⑩ 自检
```

**主歌与副歌的分工**：
- 主歌 = **给画面**（具象名词 + 动作），不评判
- 副歌 = **给态度**（抒情 + 重复），是唯一允许直白的地方
- 桥段 = **给转折**（换个说法说同一件事，或说出主歌副歌都没说的那句）

## 六、中文歌词的常见坑

| 坑 | 症状 | 解法 |
| --- | --- | --- |
| 文言倒装 | "繁花落尽处"式生硬 | 改成口语能说的话："花都落完了" |
| 抽象词堆叠 | 孤独、寂寞、忧伤、彷徨连用 | 换成具象：空椅子、未接来电、凉掉的茶 |
| 韵脚陈词 | 心/人/情/梦/痛 反复出现 | 换辙，或用 `lyric-imagery-rhyme` 找同辙的冷门字 |
| 字数失控 | 一句 5 字一句 14 字 | 按段落字数表重写 |
| 副歌无 hook | 每句都新，没有重复 | 把核心句提到句首并重复 2–3 次 |
| 人称混乱 | 一段"我"一段"你"一段"他" | 通篇统一，桥段才允许切换 |

## 七、自然度红线（创作期预防）

**AI 味的病根是"平均化"** —— 写出来的东西所有人都能写，那它就谁也不属于。
取材阶段就要守住，别等写完再补救。

- **取材三问**：能被镜头拍到吗？换到另一首歌还成立吗？有没有一个细节是别人写不出来的？
- **每段主歌 ≥ 3 个具象名词**；全首抽象情绪词 ≤ 3 个
- **全首 ≥ 1 个当代生活物件**：电量 12%、外卖备注、已读不回、末班车、快递柜
- **通用意象必须加限定**：不写"雨"，写"把伞吹翻的雨"
- **句长要有毛边**：前几句保持对齐，**允许 1 句（通常是段落末句）明显更长或更短**做落句。不要全段等长（假），也不要全段乱（唱不了）
- **情绪越重，用词越轻**：不写"想你想到流泪"，写"牙刷还在杯子里"

替换词查 `references/anti-ai-lexicon.md`；完整法则与改写流程见 `skills/lyric-naturalness/SKILL.md`。

## 八、自检清单（交付前）

- [ ] 结构标签全英文、格式正确
- [ ] 副歌韵辙统一，主歌韵脚清晰
- [ ] 同段落对应句字数差 ≤ 2 字
- [ ] 默念一遍顺口，无文言倒装
- [ ] 主歌有画面（具象名词 ≥ 5 个），副歌有态度
- [ ] 无歌手名、品牌名等无法演唱的词
- [ ] 无"为押韵而押韵"的废句
