# 中文歌词创作

> **歌词是一个人在某个处境里，对某个人说的一段话，被谱成了曲。**
> 不是诗（不靠意象密度取胜），不是散文（不负责把事讲清楚），不是文案（不负责传达信息）。
>
> 这句定义决定四件事：**有一个人**（所以要有处境，不能是泛指的情绪）、
> **对某个人**（所以要有听话的人，哪怕他不在场）、**是一段话**（所以有说出口和没说出口的区别）、
> **被谱成曲**（所以受字数和呼吸限制）。
> 下面的规则都是从这四件事推出来的，不是外部规定。完整依据见 `references/lyric-craft.md`。

## 铁律

1. **结构标签一律英文**，方括号、独占一行，标签内不写中文。
2. 歌词是**唱**的，不是读的。但**你听不到声音**——所以别用"念一遍顺不顺"来判，用可判定的四条查：
   ① 连续同声母字 ② 连续同韵母字 ③ 一句超出一口气（快歌更严，慢歌更宽）
   ④ **一句里有没有"要停下来才说完"的结构**——比较句（`比…早` `比…先`）、长定语（"我头顶的屋檐"）、
   条件句（`如果…就…`）。这些在唱的时候找不到断点，怎么断都别扭
3. 押韵服务于情绪。宁可破韵，不写"我的心/你的人"这种填充句。

## 一、结构标签与形状

### 结构标签

完整标签表（常用度、元标签、演唱指示）见 `references/suno-tags.md` 第一节 —— 唯一来源，不要在这里另存一份。写词只需记住三条：

1. **英文、方括号、独占一行**：`[Intro]` `[Verse]` `[Pre-Chorus]` `[Chorus]` `[Post-Chorus]` `[Bridge]` `[Instrumental Break]` `[Outro]` `[End]`
2. **`[Breakdown]` `[Drop]` `[whisper]` `[falsetto]` 是编曲事件的落点**，不只是结构标记（Suno 的 Style 字段读不懂长句，事件只能落在歌词标签里）
3. **纯器乐段只写标签**，标签后空一行，不写说明文字

### 结构：先写出来，再定形状

> ⚠️ **不要把结构定在写之前。** 外部实践是一致的：**先写副歌，结构后定**。
> 副歌是唯一会被反复听的部分，主歌的存在是为了把它送到听众面前。
> 先排段落 = 还不知道要送到哪，就在修路。

**动笔前只定一件事**：这是短的（卡点 / 短视频）还是完整的单曲。其余等副歌出来再说。

**写完之后回来定形状**：去 `references/song-structure.md` 第二、三节看常见排列、
定下要加哪些段落与每段几句。**表里没有排列，自己拼就是了。**

骨架好不好只看四条：**每段都有活干 / 副歌重复够 / 长歌有呼吸 / 能量有走向**。
四条满足，段落怎么排都行；不满足，套哪种排列都不行。

## 二、押韵与倒字

**判据只有两条**：副歌押住、主歌可松；相邻两句同字收尾（句式不同）要改。
其余全在 `references/rhyme-zh.md`（十三辙一览、韵字表、重韵判定、通押规则）—— **定韵时查，不预先读**。

| 段落 | 密度 |
| --- | --- |
| **副歌** | **押住**——记忆点靠它，通常句句押 |
| **主歌** | **可松**——隔句押、甚至整段不押都行 |
| 预副歌 | 押住；末句放开可以做爬升 |
| 桥段 / 尾奏 | 可换辙，或破韵收尾 |

⚠️ **押韵是辅助记忆，不是目的。** 不押时用重复、hook、旋律补记忆度；为押韵改坏一个好句子是净损失。

**定韵的时机**：看副歌自然落在哪个辙，优先用它——**不要先锁定再写内容**。
不要让韵决定内容：优先级里韵脚低于"唱句顺口"。

### 倒字（中文特有，写词时就要避开）

同一个字配上不同的旋律走向，会被听成另一个字（"我买两支"配下行 → 听成"我卖两只"）。
**先写词、后出旋律，所以只按位置查**：

| 位置 | 要求 | 要旋律吗 |
| --- | --- | --- |
| **句尾 / hook / 长音处** | 优先平声（一二声），**避免上声**——长音上被拉成"半上"，最容易听错 | 不要 |
| **连续两个三声** | 按变调后的读音校验（"老虎"实际唱成"劳虎"） | 不要 |
| **句内 ≥ 3 个同声母字** | 拗口且听不清（"蜘蛛知足"），换字 | 不要 |
| **旋律下行处** | 不用去声（四声）收尾 | 要——**有 demo 才查，没旋律不要假装念过** |

开口度大的辙（江阳 / 言前 / 发花）平声字多，**天然抗倒字**，hook 句优先用这几辙；
一七辙开口小、仄声多，说唱卡点很爽，抒情长音必倒字。

> "顺口"和"不倒字"不是一回事：前者查拗口（同声母/同韵母连排），后者查**字义被听错**。

## 三、句数（**不要一律 4 句**）

**句数是"这段话要说多少话"定的，不是算出来的。** 一句判断：**这段话需要几口气说完？**

不给范围模型就取最小值，于是每段都写 4 句。两种后果：
- **4 句副歌**：hook 只够说一遍，唱完就走，建立不了记忆
- **全段等长（4/4/4/4）**：结构层面的"AI 对称"。副歌通常比主歌长（抒情）或比主歌短（叙事），**几乎不会相等**

**只有一条是条件**（`AGENTS.md` 第 4 节第 4 条）：**同功能重复段句数相等** —— V1=V2、C1=C2。
判断维度是**功能**，不是位置：按位置判会把 V1、V2 写成不同句数，同旋律唱不了。

**其余全是参考**——结构骨架、各段典型句数、速度与字数的关系 → `references/song-structure.md`。
写完副歌再回去数（第四节 ④），主歌按与副歌的关系定（叙事型 ≥ ／ 抒情型 ≤）。

**单句字数：一句话要能一口气唱完。** 没有字数表；⚠️ 不要为了压字数改掉一个更好的句子。

**但同一段落里对应句要大致等长**——它们唱同一段旋律，差一两个字没关系，
**差到一半就装不回去**（一句 12 字配一句 6 字，那 6 字再好也进不了这一小节）。
这是**相对**的（句子之间比），不是绝对的字数表；例外是 hook 和段末落句（它们本该短）。

**中英混写**：结构一律按**主唱语言**算。整句英文按音节折算（1 音节 ≈ 1 字）；
英文只放 hook 句 / 副歌尾句，位置固定并出现 2–3 次；不要整段英文，不要指望中英互押，
也不要为了"洋气"加——夹的那句必须是中文说不出来的（语气、节奏或双关）。

## 四、写作流程

```
⓪ **定场景 + 谁在说话 + 锚句**（动笔前必做）
   · 场景边界：几点 / 在哪 / 这个人在做什么 / 场景里**实际存在**的物件
     例：不是"孤独"，而是"凌晨 00:47 的末班地铁，车厢里 3 个人，手机 4% 电"
     跳过它，写出来的就是"放之四海皆准"的平均化句子
   · **谁在说话**（比场景更关键，四个都要答）：
     (1) 这个人是谁（**处境**，不是身份）　(2) 他在对谁说（在场 / 不在场）
     (3) 什么时候说的（事后多久）　(4) **说完想干什么**（想说服对方 / 说服自己 / 只是说出来）
     ⚠️ 第四问决定语气。缺了它，写出来的是"作者在描述一段感情"，不是"一个人在说话"。
     注：这里用 (1)–(4)，**不要和流程的 ①–⑦ 混**。
   · ★ **锚句**：全首最像人说的那一句（往往就是歌名，也是 hook 的雏形）
     ⚠️ 这一句优先级最高（冲突时它赢）。
     ⚠️ **但不必在 ⓪ 憋出来**——它和 ③ 的副歌是同一件事。想不出就先往下写，
     副歌写成了，那句话自然会出现；副歌里都没有，那就是这首歌没有
   · **信息不足怎么办**：**自己给一个具体场景，一句话复述后直接开写**
     （"我先按凌晨末班地铁来写，不对你随时打断"）。
     ⚠️ 不要反复追问，也不要写空泛的——**用户纠正一个具体版本，比面对空白快得多**

① 需求澄清 + 提炼立意
   · **只问无法替他默认的**（语言）；风格/情绪/视角自己给默认值并一句话复述，直接开写
   · 已经说过的不要再问；不要为了走流程凑问题
   · 立意一句话，具体到场景，不是抽象情绪词
   （与 ⓪ 可互换先后，谁先想到都行）

② 定调性：情绪弧线 / 视角与称谓 / 待谁唱 / hook 方向

③ **先写副歌 —— 定靶心**（⚠️ 这一步在写主歌之前）
   用锚句做 hook，把"这首歌要说什么"写清。
   副歌是主歌的答案，**答案要先想清楚，再铺那条通往它的路**。
   ⚠️ 副歌写不出来 = 立意还没想清 → 退回 ⓪，**不要硬写主歌**。
   （先写主歌会怎样：写 V1 时不知道要抵达哪里，于是六个镜头并列——那就是流水账）
   ⚠️ **不要从第一行开始写整首**。这是外部实践里最一致的一条（`references/lyric-craft.md` 第一节）。

④ **定形状（副歌写出来之后才做）**
   先**数**副歌现在几句，再看主歌与它是什么关系（叙事型 ≥ / 抒情型 ≤）；速度只定量级
   段落配置去 `references/song-structure.md` 第二、三节：看常见排列，定下要加哪些段落。
   **表里没有的排列自己拼**——**结构是写出来的结果，不是写之前的前提。**

⑤ **定韵（允许事后改）**
   看副歌自然落在哪个辙，**优先用它**；写不下去可以换，主歌也可另起一辙
   ⚠️ **不要让韵去决定内容。** 优先级里韵脚低于"唱句顺口"——它不该在动笔前锁死，
   否则就成了"为押韵而押韵"

⑥ 写主歌 —— **主歌给画面，不负责走过去**
   先问：副歌那句成立的时候，人站在哪儿、手里拿着什么、刚做完什么？
   铺陈 = 给画面（具象 + 动作），不抒情；**一条线**串起来（视线 / 动作 / 同一个物件），不是六件并排
   → 预副歌（短句，情绪爬升）→ 桥段（换视角 / 换韵，说一句最真心的话）→ **尾奏（停住，不总结）**
   ⚠️ **一段要朝一个地方走**：盖住前三句读末句，站得住吗？站不住说明末句只是最后一句。

⑦ **删 —— 这一步不是"自检"**
   逐句问：**删掉它，歌更差吗？** 不更差就删。
   最后从头扫一遍：**有哪一句你会想跳过？** 想跳过的那句就是该改的。
   （别写"念一遍""听一遍"——你听不到声音，见铁律 2）
   （不查规则、不打勾——规则是参考，不是交付条件）

   删完再**分行看松紧**（每行减一版，比减掉的损失了什么）——减不出字就停，见 `lyric-naturalness`。
```

> **同一步内要取材时**，按 ⓪ 的场景边界去 `lyric-imagery-rhyme` 取意象词组与押韵候选字。

**分工**（外部一致的实践，见 `references/lyric-craft.md` 第五节 1）：

| 段落 | 干什么 |
| --- | --- |
| **主歌** | **具体**——一个场景、一个动作、一个时间点，让听众看到画面；**不解释情绪** |
| **副歌** | **普世**——把那个具体的事，变成所有人共有的那种感受；**不讲新情节** |
| **桥段** | **换视角**——说出前面没说的那句，或给一个新信息 |

**这是全曲最重要的一条分工。** 主歌如果自己在说"我很难过"，副歌就没有可升的了。

**每个后出的主歌都比前一个推进一层**（不只 V2——叙事型和说唱常有三段主歌）：
句数相等（同旋律）不代表内容可以重复。V1 铺场景，V2 就要推进 ——
换时间（"三天后"）、**换观察对象**（V1 写自己的手，V2 写对方的手；
⚠️ 换的是被看的对象，**不是叙述人称**——人称仍通篇统一，见 `references/lyric-diagnostics.md` 的"人称混乱"）、
或让 V1 埋下的物件在 V2 里发生变化（V1 里"手机 4% 电" → V2 里"关机了"）。
⚠️ 只把 V1 换个说法重写一遍，还是重复——后出的主歌要**推进**（换时间 / 换观察对象 / 物件变化），不是换个说法。

**hook 怎么造**（不只要有，还要好记、好唱）：

| 要点 | 说明 |
| --- | --- |
| **位置** | 副歌**第一句**（最先被听到），并在副歌末句或 `[Post-Chorus]` 再现，形成闭环 |
| **长度** | **通常短于周边句**（8 字句配 5–6 字）——但不是铁律：hook 也可以是最长那句，只要它最好记 |
| **开口度** | 优先开口元音（a / ang / an / ao），唱得响；闭口音（i / ü）难唱响且易倒字（见第二节） |
| **重复** | 字面重复 2–3 次，**不做变化**；三次副歌要变就变**第 4 句**（6 句副歌）或**第 3 句**（4 句副歌），不碰 hook |
| **内容** | 就是歌名或歌名的近义句；**不含抽象情绪词**（"会好的"这类不抓耳） |

⚠️ hook 三次都变 = 没有 hook。**6 句副歌**变奏留给第 4 句（想晚一点爆发可挪到第 5 句），
**第 1–3 句不动**——第 2 句是"展开 hook"，改掉等于把 hook 拆了。
**4 句副歌**没有第 4 句可动，动第 3 句（hook 之后、落句之前）。完整落法见
`references/song-structure.md` 4.3 / 4.4。

### 冲突时谁让路

写词时形式指标之间、形式指标与质量目标之间一定会打架。**优先级是固定的**：

> **私人口吻 > 唱句顺口 > 韵脚 > 字数对齐**

**不参与排序的条件**（只有这五条，其余都可让）：版本化不覆盖、结构标签格式、排版、
同功能重复段句数相等、能唱。

⚠️ **时长、绝对字数、Suno 的 Style 字符上限都不在这五条里**——前两个会让人为凑秒数 / 凑字数改句子；
后一个是 Style 字段的限制，管的是提示词，不是歌词（歌词本身没有字符上限）。

⚠️ **"对应句等长"是相对约束，不是"凑字数"**——比的是句子之间，不比对表；排在最后，让路给"顺口"。

| 冲突 | 谁赢 |
| --- | --- |
| 一句"只有他会说"的话，但字数超了 | **话留下**，把周边的句子压缩来腾空间 |
| 一句很顺的话，但不在韵上 | **话留下**，换韵脚字或改周边句去将就它 |
| 韵脚完美但句子别扭 | 韵让路 |
| 字数很齐但读起来假 | 字数对齐让路（毛边本来就是允许的） |

## 五、中文歌词的常见坑

### 歌词句不是散文句（写"两个人"的时候最容易踩）

判一句像不像歌词，**不看它有没有画面，看句法**。同一件事两种写法：

| 散文句 | 歌词句 |
| --- | --- |
| 结果真下了 你把我拽到屋檐 | 放学把校服 撑成屋檐 |
| 你说有雨 我把伞忘在教室里面 | 只说不会下雨 没有争辩 |
| 你端着面 站在门边 | 端着一碗面 站在门边 |

**没有一个判据能算出"像不像歌词"。** 能看的是这一句在说**一个处境**，还是在讲**两件先后发生的事**：

| | 两个动作的关系 | 结果 |
| --- | --- | --- |
| `你说有雨 我把伞忘在教室里面` | 先后（因为→所以） | 情节。听的人在等下一句发生什么 |
| `越过山丘 虽然已白了头` | 同时（代价） | 处境。两个动作互相咬住，谁也不用等谁 |
| `我送你离开 千里之外` | 同一件事的两面 | 处境 |

⚠️ **不要数代词，也不要数动作。** 好词里两个施动者很多：
`我送你离开 千里之外`、`天青色等烟雨 而我在等你`；一个人两件事也多：`越过山丘 虽然已白了头`。
**数量定不了这个。**

**让一句变成"处境"的几个手段**（是手段，不是规则）：

- **主语大多省略** —— 能补回来，但不用写出来
- **少用顺承的胶水** —— 结果 / 于是 / 然后 把两句话串成情节；
  ⚠️ 但**转折词不算**（虽然 / 却 / 而）——它们制造张力，不是串联
- **对方的存在不必靠他做动作**：`只说不会下雨 没有争辩`——他没说话，但他就在那儿

**合法的歌词句形态**（都成立，不必凑）：

- 名词并置：`空车厢 空站台 空的回声`
- 省略主语的动作：`放学把校服 撑成屋檐`
- 断片：`七点半的电视 播着明天`
- 重复：`再等三分钟 / 再撑三分钟`

**写两个人，不要交替对白。** 一来一回是剧本，歌词要的是**同一方的动作并置**：

❌ `你说有雨 我把伞忘在教室里面` —— 你一个动作、我一个动作，靠"于是"连着
✅ `只说不会下雨 没有争辩` —— 同一方的两个动作；对方的存在靠"没有争辩"透出来

> **关系本身是内容的时候，代词必须留**：`你是我最准的天气预报`、`别人看云 我看你的眼角`、
> `没让我看见`。删了关系就没了。**这是唯一要留的情形。**

### 再往上：一句好句子还要什么

上面讲的是"像不像歌词"。像了之后，还有两条决定它是**好句子**还是只是**合规**：

**1. 说完还有余。** 句子结束时，有东西悬着。

| 句子 | 悬着什么 |
| --- | --- |
| 故事的小黄花 从出生那年就飘着 | 飘到哪 |
| 很久没有你的消息 我也没有打听 | 为什么不打听 |
| 越过山丘 虽然已白了头 | 越过之后呢 |

说完就什么都不剩（`结果真下了 你把我拽到屋檐`），那是交代，不是歌词。

**2. 句内有张力。** 两个不匹配的东西碰在一起：
`越过山丘` × `已白了头`（达成 × 代价）、`可惜不是你` × `陪我到最后`（遗憾 × 期待）。

单向陈述的句子信息清楚，但只有一个方向。

⚠️ 这两条是**写好**的标准，不是**合格**的标准。不达标不算错，只是还差一口气。

### 其余的坑、症状 → 处方

### 四个外部测试（只有后两个你能自己查）

1. **哼回测试**：只听一遍，20 分钟后还能哼出副歌吗 —— 要真人做，你做不到，**别假装**做过
2. **陌生人反应**：看他在副歌时的表情 —— 同上
3. **只看副歌**：只读副歌，知道这首歌在说什么吗？不知道 = 副歌没承担它的职责

## 八、排版规范（严格遵守）

**歌词正文必须放在代码块里**，保证可一键复制、不被 markdown 折叠。

```
[Intro]

[Verse 1]
第一句歌词
第二句歌词
第三句歌词

[Chorus]
第一句歌词
第二句歌词
```

| 项 | 要求 |
| --- | --- |
| 结构标签 | 独占一行，英文，方括号包裹，**前后不加标点** |
| **每句歌词** | **独占一行，句与句之间不留空行** |
| 段落之间 | 空**一行**（且只空一行） |
| 句内断句 | 用**半角空格**分隔（"我买两支 买咗好耐"），不用标点，不用全角空格 |
| 演唱指示 | `[whisper]` `[falsetto]` 等单独成行，写在对应段落前 |
| 空段落 | 纯器乐段只写标签，标签后空一行，不写内容 |

> ⚠️ **不要每句之间都空一行** —— 那是段落格式不是歌词格式，复制进 Suno 会带一堆空行。

**交付文档结构**：

```markdown
# 歌词 ·《歌名》v1          ← 首版也写 v1，不设"首次不带版本号"的特例

> 上一版：outputs/{歌曲名}/…-v0-20260101.md    ← 首版写"无"

## 歌词                  ← 代码块，可直接复制

---
**话**：选了什么（段落配置 / 速度量级）+ 改了什么 + 哪里还不满意。
```

**就这些。** 交付纪律（≤5 行、不自证、不主动展开）统一在 `AGENTS.md` 第 4 节，本文件不重复。

**被问才展开**：结构理由 / 韵辙与密度 / 意象怎么选——**不主动交**（`AGENTS.md` 第 4 节）。
