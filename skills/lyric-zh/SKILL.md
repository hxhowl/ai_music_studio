# 中文歌词创作

> **歌词是一个人在某个处境里，对某个人说的一段话，被谱成了曲。**
> 不是诗（不靠意象密度取胜），不是散文（不负责把事讲清楚），不是文案（不负责传达信息）。
>
> 这句定义决定四件事：**有一个人**（所以要有处境，不能是泛指的情绪）、
> **对某个人**（所以要有听话的人，哪怕他不在场）、**是一段话**（所以有说出口和没说出口的区别）、
> **被谱成曲**（所以受字数和呼吸限制）。
> 下面的规则都是从这四件事推出来的，不是外部规定。完整依据见 `references/lyric-craft.md`。

## 铁律

1. **结构标签一律英文**，方括号、独占一行，标签内不写中文。
2. 歌词是**唱**的，不是读的。但**你听不到声音**——所以别用"念一遍顺不顺"来判，用可判定的四条查：
   ① 连续同声母字 ② 连续同韵母字 ③ 一句超出一口气（快歌更严，慢歌更宽）
   ④ **一句里有没有"要停下来才说完"的结构**——比较句（`比…早` `比…先`）、长定语（"我头顶的屋檐"）、
   条件句（`如果…就…`）。这些在唱的时候找不到断点，怎么断都别扭
3. 押韵服务于情绪。宁可破韵，不写"我的心/你的人"这种填充句。

## 一、结构标签与模板

### 结构标签

完整标签表（常用度、元标签、演唱指示）见 `references/suno-tags.md` 第一节 —— 唯一来源，不要在这里另存一份。写词只需记住三条：

1. **英文、方括号、独占一行**：`[Intro]` `[Verse]` `[Pre-Chorus]` `[Chorus]` `[Post-Chorus]` `[Bridge]` `[Instrumental Break]` `[Outro]` `[End]`
2. **`[Breakdown]` `[Drop]` `[whisper]` `[falsetto]` 是编曲事件的落点**，不只是结构标记（Suno 的 Style 字段读不懂长句，事件只能落在歌词标签里）
3. **纯器乐段只写标签**，标签后空一行，不写说明文字

### 结构：先写出来，再定形状

> ⚠️ **不要先选模板再写。** 外部实践是一致的：**先写副歌，结构后定**。
> 副歌是唯一会被反复听的部分，主歌的存在是为了把它送到听众面前。
> 先挑骨架 = 还不知道要送到哪，就在修路。

**动笔前只定一件事**：这是短的（卡点 / 短视频）还是完整的单曲。其余等副歌出来再说。

**写完之后回来定形状**，去 `references/song-structure.md` 第二、三节对照常见骨架
（那里的 T1–T9 是**已有形状的归纳，不是九选一**，也可以自己拼）。

骨架好不好只看四条：**每段都有活干 / 副歌重复够 / 长歌有呼吸 / 能量有走向**。
四条满足，段落怎么排都行；不满足，套哪个模板都不行。

完整韵字表见 `references/rhyme-zh.md`。

| 发花 | a ia ua | 明亮、开阔 | 花 家 话 下 沙 芽 霞 |
| 梭波 | o e uo | 沉稳、叙述 | 河 火 我 说 破 过 朵 |
| 乜斜 | ie üe | 婉转、清冷 | 月 雪 夜 谢 别 街 蝶 |

| 怀来 | ai uai | 舒展、叹息 | 来 开 海 爱 外 待 快 |
| 灰堆 | ei ui | 柔婉、回落 | 悲 飞 水 泪 回 灰 醉 |
| 遥条 | ao iao | 悠远、飘逸 | 高 老 笑 道 草 桥 照 |
| 由求 | ou iu | 忧郁、绵长 | 愁 秋 留 手 头 酒 旧 |
| 言前 | an ian uan üan | 开阔、舒展、最常用 | 前 天 年 面 见 远 山 圆 |
| 人辰 | en in un ün | 深沉、内敛 | 心 深 真 门 春 云 群 |
| 江阳 | ang iang uang | 昂扬、宏大 | 光 长 方 上 乡 唱 望 |
| 中东 | eng ing ong iong | 浑厚、共鸣强 | 风 梦 中 空 声 影 情 |

**选韵**：开口度配情绪（激昂用江阳/言前/发花，低回用一七/姑苏/由求）；副歌定死一辙，主歌可换辙制造对比；言前与人辰（-an / -en）可通押但慎用，容易糊；一七辙字多好押但易写得绵软无骨；仄声韵（三四声）比平声更有推进力，说唱和摇滚常用
——但**只对无拖腔的卡点句成立**：凡是句尾拖长音、hook、大跳的位置，回到本节「声调与旋律」的倒字判定（优先平声）。
（这就是为什么"一七辙最易也最险"：开口小 + 仄声多，说唱卡点很爽，抒情长音必倒字。）

**韵脚位置**：句尾韵（默认）；句中韵（顿挫处押，增密度，说唱常用）；双押/三押（末尾连续 2–3 字同韵）；转韵（段落切换时换辙，标记情绪转折）。

**押韵密度**（副歌押住，主歌可松）：

| 段落 | 建议 |
| --- | --- |
| **副歌** | **押住**——记忆点靠它，通常句句押 |
| **主歌** | **可松**——隔句押、甚至整段不押都行（上一句不一定接下一句，见 `references/lyric-craft.md` 第三节） |
| 预副歌 | 押住；末句放开可以做爬升 |
| 桥段 / 尾奏 | 可换辙，或破韵收尾 |

⚠️ **押韵是辅助记忆，不是目的。** 行业共识是"押韵非必需"——不押时用重复、hook、旋律补记忆度。
为押韵改坏一个好句子，是净损失。

- ⚠️ **要么押密，要么当作不靠韵的歌** —— 只有偶数句押韵（6 句押 3 句）在中文里听感接近无韵。
  叙事民谣 / 说唱本来就不靠韵，那是另一回事，不必解释。
- ⚠️ **顶真可以让一句不押，这是手法不是松了密度。** 上一句的末字做下一句的开头时
  （"往前走 出口越来越**近**／**近**到能听见 地面的风声"），那句为了接住顶真会落到别的辙。
  **判据很硬**：下一句必须真的以本句末字开头；做不到就是普通破韵，照上表算。
- ⚠️ **句句押 ≠ 可以重复同一个韵字。** 但"重韵"要按**听感**判，不按韵书判：

  | 情况 | 判定 |
  | --- | --- |
  | **相邻两句**同字收尾，句式不同 | **偷懒，必改**——连着两句都落同一个字，听感上立刻暴露 |
  | **相邻两句**同字收尾，但**是排比**（句式相同，只换一个关键词） | **是手法，留着**——"再等三分钟／再撑三分钟"，重复本身就在推情绪。<br>判据：去掉尾字后，两句的前半截结构一样吗？一样就是排比 |
  | 隔 2 句以上同字，**且是刻意的呼应** | **是手法，留着**（副歌首尾问答、hook 复沓、顶针） |
  | 隔 2 句以上同字，纯属词穷 | 能听，但优先换同辙另一个字 |
  | 一段内同一个字**作韵脚**出现 **≥3 次** | 无论隔多远都显词穷，必改（hook 里的重复字不算，那是复沓） |

  > 传统韵书里"重韵"指同一韵段内重复用同一个韵字，**不分相邻**——那是填词考试的规矩，
  > 流行歌不套它。听众不会去数一段里有几个"园"，但会立刻听出连续两句都落"园"。
  > 实测例子：副歌「这是不是个动物园／……／这是疯狂的动物园」——同一个"园"字，隔了 3 句，
  > **是首尾问答的结构，不是重韵。别把它改掉。**
- 说唱 / 长句风格可放宽到隔句押——放宽是你的判断，**不用为它写一段说明**。

### 声调与旋律（中文特有的"倒字"）

英文要求重音落在拍上（见 `lyric-en` 的重音对齐），**中文的对应物是声调与旋律走向的冲突**——
同一个字配上不同的旋律走向，会被听成另一个字，这叫"倒字"。

- "我买两支"配下行旋律 → 听成"我卖两只"
- "你好"配上行的两个高音 → 听成"尼蒿"

**四条可执行判定**：

> ⚠️ 本流程是先写词、后出旋律，写词时**通常没有旋律可参照**。
> 所以第 1 条按**位置**执行（不需要旋律），第 2、4 条在**已知旋律 / 有 demo 时**再校一遍。

| 位置 | 要求 | 需要旋律吗 |
| --- | --- | --- |
| **句尾 / hook / 长音处** | 优先平声（一、二声），**避免上声（三声）** —— 三声字在长音上必然被拉成"半上"，最容易听错 | **不需要**（按位置默认执行） |
| **旋律下行处** | 不用去声（四声）收尾 —— 去声本身就是下降的，配下行会加倍下滑 | 需要 |
| **连续两个三声** | 前一字变调读二声，要按**变调后**的读音校验（"老虎"实际唱成"劳虎"） | **不需要** |
| **句内 ≥ 3 个同声母字** | 拗口且听不清（"蜘蛛知足"），换字 | **不需要** |

**与选韵的关系**：这就是"一七辙最易也最险"的深层原因 ——
`i` `ü` 开口度小、仄声字多，既难唱响又容易倒字；
`江阳` `言前` `发花` 开口大、平声字多，**天然抗倒字**，hook 句优先用这几辙。

**检查法**：你读不出声，所以分两条线查——
① **按位置查**（不需要旋律）：句尾 / hook / 长音位是否平声收尾；有无连续两个三声；有无 ≥3 个同声母字；
② **有旋律 / demo 时**再按走向校"下行处不用去声"，没旋律就跳过，不要假装念过。


> "顺口"和"不倒字"不是一回事：前者查拗口（同声母/同韵母连排），后者查**字义被听错**。

## 三、句数（**不要一律 4 句**）

给范围不给规则，模型就取最小值 —— 于是每段都写 4 句。两个理由说明为什么不行：

- **4 句副歌**：hook 只够说一遍，唱完就走，建立不了记忆。要堆情绪至少 6 句——第 1 句记住，第 2 句展开，第 3 句往上推
- **全段等长（4/4/4/4）**：结构层面的"AI 对称"。真人写歌，副歌通常比主歌长（抒情）或比主歌短（叙事），**几乎不会相等**

**句数是"这个情绪要说多少话"定的，不是用秒数算出来的。**

### 决策流程（**写完副歌再回来做这一步**）

> ⚠️ **顺序很重要**：这一节是第四节第 ④ 步的展开。
> **副歌必须先写完**（第四节 ③）——你才知道要写多长、情绪要堆到哪。
> 先算结构再写副歌，结构对了但副歌没话说——这是最容易踩的顺序错误。

所有速查表、模板库、句数判断都在 **`references/song-structure.md`**（唯一事实源）。
下表「查哪里」一律指该文件的节号（不是本文件的）。

| 步 | 做什么 | 查 `song-structure.md` |
| --- | --- | --- |
| ① 认形状 | 副歌已写出来，对照它长成哪一类（**命名，不是选**） | 第三节 |
| ② 定速度量级 | 用户给了具体 BPM 就沿用；没说只定**慢 / 中 / 快**，**不填数字**——数字与区间归编曲侧 | 第六节 |
| ③ 数句数 | **数副歌写出来几句**，问"这段话需要几口气说完"；主歌按与副歌的关系定 | 第四节 |
| ④ 核对关系 | 同功能重复段是否相等；主歌 / 预副 / 副歌是否有差异 | 第五节 |

> ⚠️ **句数是"这个情绪要说多少话"定的，不是算出来的。**
> 不要用秒数倒推句数——那样每一段都在凑长度，句子没有非写不可的理由。

### 结构上只有一条是条件

`AGENTS.md` 第 4 节第 4 条：**同功能重复段句数相等**。
时长**不是条件**——它随风格走，参考区间见 `AGENTS.md` 第 5 节。

⚠️ 判断维度是**功能**，不是位置——按位置判会把 V1、V2 写成不同句数（同旋律，唱不了）。

**其余全是参考**，卡壳时去 `references/song-structure.md` 查。下面几条只是常用提示，**别当门槛**：

- **模板只给骨架**：句数看"说完没有"，**不是照抄表里的数字**
- **快歌句子短、慢歌句子长**——速度只改句子的肺活量，**不改句数**（同一个情绪要说几句，跟速度无关）
- **主歌 / 预副歌 / 副歌句数有差异**更好听；桥段、尾奏不必强行凑差异
- 叙事点缀型副歌可以只有 4 句，靠出现次数建立记忆
- 长句（古风 / 氛围）一句占 2 小节，句数少、字数多，同样成立

### 单句字数：不给表，给一句判断

**一句话要能一口气唱完。** 就这一条。

- 快歌句子天然更短（一口气装的字少），慢歌可以长
- 长句风格（古风 / 氛围）一句占 2 小节，字数可以是常规的两倍
- **不设字数表。** 字数是速度和句子长度的结果，不是写词时要对着的目标

> ⚠️ **不要为了字数改掉一个更好的句子。**
> 实测教训：`我说 哥 周一还得交周报`（全首最像真人的一句）就是为压字数 + 凑 AABB 被改成
> `我烦恼 周一汇报还得交` 的——零收益，纯损失，而自检照样判"通过"。
> 一句话明显长到念不完（周边 8 字它 16 字）时才值得动，动之前先问：**改完是不是更难听了？**

### 中英混写

中文歌里夹英文很常见，但**结构一律按主唱语言算**。

| 问题 | 规则 |
| --- | --- |
| 用哪个 skill | 以**主唱语言**定：中文为主 → 本 skill；英文为主 → `lyric-en` |
| 字数怎么算 | 中文部分按中文字数；**整句英文**按音节算（1 音节 ≈ 1 字估）；**句内混写**（"我按下 play"）中文按字、英文 1 音节 ≈ 1 字，合并计入总长度 |
| 押韵 | 中文部分照十三辙；英文词不进十三辙，可自押，**但不要指望中英互押** |
| 英文放哪 | hook 句、副歌尾句、预副歌的爬升句 —— 位置要**固定并出现 2–3 次**才成立 |
| 可唱性 | 英文部分仍要**重音落拍**（见 `lyric-en` 的重音对齐），否则在中文旋律上会吞字 |

⚠️ 三个坑：
1. **不要整段英文** —— 会破坏中文字数对齐与韵脚密度
2. **不要为了"洋气"加英文** —— 夹的那一句必须是中文说不出来的（语气、节奏或双关），否则是装饰
3. **结构标签不受影响** —— 混写时标签仍然全英文

**对齐只是参考**：同段落对应句字数差太多会唱不顺（大体 ±2 字内舒服），
但**别为了对齐改掉更好的句子**——理由见第三节字数说明。
**长句风格看总字数和肺活量，不看句数**：4 句长句 ≈ 8 句常规句的听感（一句占 2 小节）。

**被问到时能说清就行**（不要主动交）：选了哪个模板、为什么；速度量级；每段几句、为什么。
⚠️ **不要写"速度改了所以句数调整"**——速度不改句数（见上一条）。（交付形态见 `AGENTS.md` 第 4 节）

## 四、写作流程

```
⓪ **定场景 + 写那句锚句**（动笔前必做）
   · 场景边界：几点 / 在哪 / 这个人在做什么 / 场景里**实际存在**的物件
     例：不是"孤独"，而是"凌晨 00:47 的末班地铁，车厢里 3 个人，手机 4% 电"
     跳过它，写出来的就是"放之四海皆准"的平均化句子
   · **谁在说话**（比场景更关键，四个都要答）：
     ① 这个人是谁（**处境**，不是身份）② 他在对谁说（在场 / 不在场）
     ③ 什么时候说的（事后多久）④ **说完想干什么**（想说服对方 / 说服自己 / 只是说出来）
     ⚠️ 第四问决定语气。缺了它，写出来的是"作者在描述一段感情"，不是"一个人在说话"。
   · ★ **锚句**：全首最像人说的那一句（往往就是歌名，也是 hook 的雏形）
     ⚠️ 这一句优先级最高（冲突时它赢）。
     ⚠️ **但不必在 ⓪ 憋出来**——它和 ③ 的副歌是同一件事。想不出就先往下写，
     副歌写成了，那句话自然会出现；副歌里都没有，那就是这首歌没有
   · **信息不足怎么办**：**自己给一个具体场景，一句话复述后直接开写**
     （"我先按凌晨末班地铁来写，不对你随时打断"）。
     ⚠️ 不要反复追问，也不要写空泛的——**用户纠正一个具体版本，比面对空白快得多**

① 需求澄清 + 提炼立意
   · **只问无法替他默认的**（语言）；风格/情绪/视角自己给默认值并一句话复述，直接开写
   · 已经说过的不要再问；不要为了走流程凑问题
   · 立意一句话，具体到场景，不是抽象情绪词
   （与 ⓪ 可互换先后，谁先想到都行）

② 定调性：情绪弧线 / 视角与称谓 / 待谁唱 / hook 方向

③ **先写副歌 —— 定靶心**（⚠️ 这一步在写主歌之前）
   用锚句做 hook，把"这首歌要说什么"写清。
   副歌是主歌的答案，**答案要先想清楚，再铺那条通往它的路**。
   ⚠️ 副歌写不出来 = 立意还没想清 → 退回 ⓪，**不要硬写主歌**。
   （先写主歌会怎样：写 V1 时不知道要抵达哪里，于是六个镜头并列——那就是流水账）
   ⚠️ **不要从第一行开始写整首**。这是外部实践里最一致的一条（`references/lyric-craft.md` 第一节）。

④ **定形状（副歌写出来之后才做）**
   先**数**副歌现在几句，再看主歌与它是什么关系（叙事型 ≥ / 抒情型 ≤）；速度只定量级
   骨架去 `references/song-structure.md` 第二、三节对照——那里是**已有形状的归纳，不是九选一**，
   也可以自己拼。**结构是写出来的结果，不是写之前选的前提。**

⑤ **定韵（允许事后改）**
   看副歌自然落在哪个辙，**优先用它**；写不下去可以换，主歌也可另起一辙
   ⚠️ **不要让韵去决定内容。** 优先级里韵脚低于"唱句顺口"——它不该在动笔前锁死，
   否则就成了"为押韵而押韵"

⑥ 写主歌 —— **主歌是"怎么走到副歌那句话"的过程**
   先问：从什么状态出发，才能让副歌成立？
   铺陈 = 给画面（具象 + 动作），不抒情；**一条线**串起来（视线 / 动作 / 同一个物件），不是六件并排
   → 预副歌（短句，情绪爬升）→ 桥段（换视角 / 换韵，说一句最真心的话）→ **尾奏（停住，不总结）**
   ⚠️ **一段要朝一个地方走**：盖住前三句读末句，站得住吗？站不住说明末句只是最后一句。

⑦ **删 —— 这一步不是"自检"**
   逐句问：**删掉它，歌更差吗？** 不更差就删。
   最后从头扫一遍：**有哪一句你会想跳过？** 想跳过的那句就是该改的。
   （别写"念一遍""听一遍"——你听不到声音，见铁律 2）
   （不查规则、不打勾——规则是参考，不是交付条件）
```

> **同一步内要取材时**，按 ⓪ 的场景边界去 `lyric-imagery-rhyme` 取意象词组与押韵候选字。

**分工**（外部一致的实践，见 `references/lyric-craft.md` 第二节）：

| 段落 | 干什么 |
| --- | --- |
| **主歌** | **具体**——一个场景、一个动作、一个时间点，让听众看到画面；**不解释情绪** |
| **副歌** | **普世**——把那个具体的事，变成所有人共有的那种感受；**不讲新情节** |
| **桥段** | **换视角**——说出前面没说的那句，或给一个新信息 |

**这是全曲最重要的一条分工。** 主歌越具体，副歌越有东西可升；
主歌如果自己在说"我很难过"，副歌就没有可升的了。

**每个后出的主歌都比前一个推进一层**（不只 V2——T3、T6 有三段主歌）：
句数相等（同旋律）不代表内容可以重复。V1 铺场景，V2 就要推进 ——
换时间（"三天后"）、**换观察对象**（V1 写自己的手，V2 写对方的手；
⚠️ 换的是被看的对象，**不是叙述人称**——人称仍通篇统一，见第五节"人称混乱"）、
或让 V1 埋下的物件在 V2 里发生变化（V1 里"手机 4% 电" → V2 里"关机了"）。
⚠️ 只把 V1 换个说法重写一遍，还是重复——后出的主歌要**推进**（换时间 / 换观察对象 / 物件变化），不是换个说法。

**hook 怎么造**（不只要有，还要好记、好唱）：

| 要点 | 说明 |
| --- | --- |
| **位置** | 副歌**第一句**（最先被听到），并在副歌末句或 `[Post-Chorus]` 再现，形成闭环 |
| **长度** | **通常短于周边句**（8 字句配 5–6 字）——但不是铁律：hook 也可以是最长那句，只要它最好记 |
| **开口度** | 优先开口元音（a / ang / an / ao），唱得响；闭口音（i / ü）难唱响且易倒字（见第二节） |
| **重复** | 字面重复 2–3 次，**不做变化**；三次副歌要变就变**第 4 句**（6 句副歌的标准变奏位，见下），不碰 hook |
| **内容** | 就是歌名或歌名的近义句；**不含抽象情绪词**（"会好的"这类不抓耳） |

⚠️ hook 三次都变 = 没有 hook。变奏留给**第 4 句**（6 句副歌的标准变奏位，想晚一点爆发可挪到第 5 句），
**第 1–3 句不动**——第 2 句是"展开 hook"，改掉等于把 hook 拆了。
（6 句改 1 句 ≈ 17%，hook 最稳；完整落法见 `references/song-structure.md` 第四节。）

### 冲突时谁让路

写词时形式指标之间、形式指标与质量目标之间一定会打架。**优先级是固定的**：

> **私人口吻 > 唱句顺口 > 韵脚 > 字数对齐**

**不参与排序的条件**（只有这五条，其余都可让）：
版本化不覆盖、结构标签格式、排版、同功能重复段句数相等、能唱。

⚠️ 时长和字数都不在这五条里——它们随风格、速度、句子长度一起变，
写成条件就会为了凑秒数改句子。

⚠️ **「Suno ≤200 字符」不在作词侧**——那是 Style 字段的限制，管的是提示词，不是歌词
（歌词本身没有字符上限）。别把两侧的条件混着算。

⚠️ **"单句字数上限"不在其中**——它是**参考**，不是硬约束。
**为了压字数牺牲句子，是错的。**

| 冲突 | 谁赢 |
| --- | --- |
| 一句"只有他会说"的话，但字数超了 | **话留下**，把周边的句子压缩来腾空间 |
| 一句很顺的话，但不在韵上 | **话留下**，换韵脚字或改周边句去将就它 |
| 韵脚完美但句子别扭 | 韵让路 |
| 字数很齐但读起来假 | 字数对齐让路（毛边本来就是允许的） |

### 不许推诿：必须做出选择

这是"防御性"的第二张脸——**不敢下判断，把决策推回给用户**。

❌ 实测原话（《疯狂动物园》v7）：

> 「两个画面都成立：现在这版更强调"动物在上流社会的休闲"，狮子理发那版更强调"动物在做人的服务业"。**看你想要哪一种。**」
> 「**可留可不留**的两处」

你请它做创作，它给你出选择题。这跟"写一堆说明"是同一个病：**不承担创作责任**。

| 不许写 | 要写 |
| --- | --- |
| 两种都成立，看你想要哪一种 | 我选 A，因为（一句理由） |
| 可留可不留 / 或者也可以 | （直接决定留还是不留） |
| 若想更克制，可换成 X | 已经换成 X（如果真觉得更好）／不提 |

**想给备选，最多一句**：「另一个方向是 X，我选了 Y 因为 Z。」——一句话，然后闭嘴。

⚠️ **改词时，不得为了形式指标改动已经通过自检的"私人口吻"句。**

实测反例（2026-10-31《疯狂动物园》）：v6 的 `我说 哥 周一还得交周报`
被改成 `我烦恼 周一汇报还得交`，理由是凑 Bridge 的 AABB——
**但"报"与"好"同为遥条辙，那一句本来根本不用动。**
结果是全首最像真人的一句被形式指标改坏了，而自检照样判通过。

**要动这种句子，必须在改动对照表里写明"为什么值得"**；写不出理由就别动。

## 五、中文歌词的常见坑

### 歌词句不是散文句（写"两个人"的时候最容易踩）

判一句像不像歌词，**不看它有没有画面，看句法**。同一件事两种写法：

| 散文句 | 歌词句 |
| --- | --- |
| 结果真下了 你把我拽到屋檐 | 放学把校服 撑成屋檐 |
| 你说有雨 我把伞忘在教室里面 | 只说不会下雨 没有争辩 |
| 你端着面 站在门边 | 端着一碗面 站在门边 |

**三条可查的差别**：

1. **一句里有几个动作**：散文一句常套两三个分句（"我说…你没…"），歌词一句通常只落一个动作
2. **主语写不写**：散文必须写；歌词大多省略。**能补回来，但不用写出来**
3. **有没有连接词**：结果 / 因为 / 但是 / 于是 —— 出现在歌词里就是把事件交代写进来了

**合法的歌词句形态**（都成立，不必凑）：

- 名词并置：`空车厢 空站台 空的回声`
- 省略主语的动作：`放学把校服 撑成屋檐`
- 断片：`七点半的电视 播着明天`
- 重复：`再等三分钟 / 再撑三分钟`

**写两个人，不要交替对白。** 一来一回是剧本，歌词要的是**同一方的动作并置**：

❌ `你说有雨 我把伞忘在教室里面` —— 两个主语各做一个动作
✅ `只说不会下雨 没有争辩` —— 同一方的两个动作；对方的存在靠"没有争辩"透出来

> **判据**：一句里出现两个以上「我 / 你」，基本就是散文句。删掉主语还读得通，就删。
> **但要留**——当关系本身是内容的时候：`你是我最准的天气预报`、`别人看云 你看我的眼角`、
> `没让我看见`。这些句子的主语不能省，省了关系就没了。
> 代词不是数量问题，是「**每个动作都带主语**」的问题。

### 再往上：一句好句子还要什么

上面讲的是"像不像歌词"。像了之后，还有两条决定它是**好句子**还是只是**合规**：

**1. 说完还有余。** 句子结束时，有东西悬着。

| 句子 | 悬着什么 |
| --- | --- |
| 故事的小黄花 从出生那年就飘着 | 飘到哪 |
| 很久没有你的消息 我也没有打听 | 为什么不打听 |
| 越过山丘 虽然已白了头 | 越过之后呢 |

说完就什么都不剩（`结果真下了 你把我拽到屋檐`），那是交代，不是歌词。

**2. 句内有张力。** 两个不匹配的东西碰在一起：
`越过山丘` × `已白了头`（达成 × 代价）、`可惜不是你` × `陪我到最后`（遗憾 × 期待）。

单向陈述的句子信息清楚，但只有一个方向。

⚠️ 这两条是**写好**的标准，不是**合格**的标准。不达标不算错，只是还差一口气。

### 其余的坑

| 坑 | 症状 | 解法 |
| --- | --- | --- |
| 文言倒装 | "繁花落尽处"式生硬 | 改成口语能说的话："花都落完了" |
| 抽象词堆叠 | 孤独、寂寞、忧伤、彷徨连用 | 换成具象：空椅子、未接来电、凉掉的茶 |
| 韵脚陈词 | 心/人/情/梦/痛 反复出现 | 换辙，或用 `lyric-imagery-rhyme` 找同辙的冷门字 |
| 字数失控 | 一句 5 字一句 14 字 | 按"一口气唱完"重写：拆句或删字 |
| 副歌无 hook | 每句都新，没有重复 | 把核心句提到句首并重复 2–3 次 |
| 人称混乱 | 一段"我"一段"你"一段"他" | 通篇统一，桥段才允许切换 |

## 六、自然度：三个准星（都是"减"的方向）

AI 味的病根是"平均化"——写出来的东西所有人都能写，那它就谁也不属于。

写作时只盯三件事：

1. **能被镜头拍到吗**：拍不到"孤独"，拍得到"牙刷还在杯子里"；
   同理不写"雨"，写"把伞吹翻的雨"。
   **形容词是作者在评价，名词和动词是事物本身**——删掉评价，只留事物
2. **情绪越重，用词越轻**：不写"想你想到流泪"，写"我没删"
3. **同一个物件再出现一次时，状态要变**（没摘 → 被嚼烂 → 还在）

⚠️ 这三条是**准星，不是清单**——写到哪儿卡住才看，不要逐条对着改。

写完不确定"这算不算歌词" → 走 `skills/lyric-naturalness/SKILL.md` 的三条判定。
替换词查 `references/anti-ai-lexicon.md`。

## 七、交付检查

### 核对 `AGENTS.md` 第 4 节的第 1–5 条

本文件**不复述条件内容**。
去读那五条：**版本化 / 结构标签 / 排版 / 句数相等 / 能唱**。

> 全过就写一句话结论，不罗列、不打分。**这五条之外没有门槛。**

### 四个外部测试（只有后两个你能自己查）

1. **哼回测试**：只听一遍，20 分钟后还能哼出副歌吗 —— 要真人做，你做不到，**别假装**做过
2. **陌生人反应**：看他在副歌时的表情 —— 同上
3. **只看副歌**：只读副歌，知道这首歌在说什么吗？不知道 = 副歌没承担它的职责
4. **一句能当歌名**：有没有一句话，短到能当标题、又撑得起整首

### 下面是诊断表 —— 卡壳时才查，**不是交付门槛**

> 这些是"好歌词长什么样"，**不是"合格歌词的条件"**。
> **写顺了就不用看；只有当你觉得"哪里不对但说不上来"时才来翻。**
> ⚠️ 把它们当门槛，模型就会去凑条件而不是写好歌——这是实测踩过的坑（2026-10-31）。

**整体走向（怀疑"不成篇"时先查这里）**
- [ ] **有一条走向**：全首的情绪或处境要移动（⚠️ 场景变化 ≠ 情感变化）。
      **不一定是故事**——视线一路往下、同一个念头越想越深，都算
- [ ] **句间有东西连着**：抽 3 处相邻句，能说出凭什么挨在一起——因果 / 递进 / 转折 / 对比，
      **或者并置**（同一个场景的侧面、同一个物件的两个状态）。
      ⚠️ **并置不算流水账**；六件事互不相关、连一条线都没有，才算
- [ ] **副歌的必然性**：副歌是从主歌"逼"出来的，不是换个话题再写一段
- [ ] **段末落在某处**：可以比首句更远，也可以只是收住
- [ ] **有一个物件出现 ≥ 2 次且状态发生了变化**（线索物，不是装饰）

**句子质量（怀疑"不像歌词""太散"时查）**
- [ ] **不是每句都在说"谁做了什么"** —— 一句里两个以上"我 / 你"基本就是散文句；
      删掉主语还读得通，就删（第五节）
- [ ] 副歌韵辙统一；**押韵密度对着第二节的表看**（主歌至多放开 1 句且不是末句，副歌句句押）
- [ ] **重韵按听感判**：相邻两句同字要改；一段内同一个字 ≥3 次要改；
      隔开且刻意的呼应（副歌首尾、hook 复沓）**不算重韵，别改**（见第二节）
- [ ] 同段落对应句字数大体齐（±2 内舒服）—— **hook 和段末落句除外**，它们本来就该短/长
- [ ] **拗口自查**（别写"念一遍顺口"——你读不出声）：连续同声母字、连续同韵母字、
      一句超一口气；无文言倒装、无"为押韵而押韵"的废句
- [ ] **无倒字**：句尾 / hook / 长音位是平声收尾；无连续两个三声；一句内无 ≥3 个同声母字（见第二节）
- [ ] **hook 基本满足**：在副歌首句、开口元音、字面重复 2–3 次、就是歌名；长度通常短于周边句（也可以是最长那句，只要最好记）
- [ ] **后出的主歌推进了一层**（换时间 / 换观察对象 / 物件变化），不是换个说法重复
- [ ] 主歌**具体**、副歌**普世**、桥段换视角

**自然度（怀疑"太 AI 了"时查，第六节）**
- [ ] 每段有能被镜头拍到的细节，**但不数个数**（凑数就会写成报菜名）；抽象情绪词很少
- [ ] **细节成链不成堆** —— 抽句测试 + 主语测试过得去，不是一行一件的分镜表
- [ ] 通用意象都加了限定（不是"雨"，是"把伞吹翻的雨"）
- [ ] **有一句"只有这个人会说"的话**；句长有毛边，不是全段等长
      （这一项优先级最高——它是"这里最值得改"的信号，不是判合格的条件）

**结构与句数（怀疑"结构不对"时查，第三节）**
- [ ] **不是每段都 4 句** —— 但句数是数出来的，不是照着表定的；偏离表里的数字不算错
- [ ] **主歌与副歌句数有差异**（相等也可——T2/T7 就是相等；相等时要靠 Pre-Chorus 与能量对比分野）
- [ ] **副歌没吃掉整首歌**：副歌次数 ≤ 4（只有这一半是硬的）。相邻两次副歌完全一样也成立——
      差异交给演唱与编曲；**不要为了"有变化"去改一句本来更好的词**
      （实测踩过：把"我一咧嘴 你比我先笑"改成"翻个身 把被子拉高"，只为了让第二段副歌不一样）
- [ ] **模板理由与实际结构一致**：说"末次加长"就真的加长了，不能两头挂着
- [ ] 副歌 ≥ 3 次时，有一处爬升或留白（Pre-Chorus / 器乐段 / 抽空），不是副歌连着砸

**关于"及格线"**

只有开头那五条有及格线。**诊断表不设及格线** —— 它不是考试，是工具箱。
诊断表查出问题，按 `lyric-naturalness` 的三条判定先看"是不是歌词"；
其中**私人口吻**（"有没有一句只有这个人会说的话"）是优先级最高的信号，
但它不判不合格——它只是"这里最值得改"。

## 八、排版规范（严格遵守）

**歌词正文必须放在代码块里**，保证可一键复制、不被 markdown 折叠。

```
[Intro]

[Verse 1]
第一句歌词
第二句歌词
第三句歌词

[Chorus]
第一句歌词
第二句歌词
```

| 项 | 要求 |
| --- | --- |
| 结构标签 | 独占一行，英文，方括号包裹，**前后不加标点** |
| **每句歌词** | **独占一行，句与句之间不留空行** |
| 段落之间 | 空**一行**（且只空一行） |
| 句内断句 | 用**半角空格**分隔（"我买两支 买咗好耐"），不用标点，不用全角空格 |
| 演唱指示 | `[whisper]` `[falsetto]` 等单独成行，写在对应段落前 |
| 空段落 | 纯器乐段只写标签，标签后空一行，不写内容 |

> ⚠️ **不要每句之间都空一行** —— 那是段落格式不是歌词格式，复制进 Suno 会带一堆空行。

**交付文档结构**：

```markdown
# 歌词 ·《歌名》v1          ← 首版也写 v1，不设"首次不带版本号"的特例

> 上一版：outputs/{歌曲名}/…-v0-20260101.md    ← 首版写"无"

## 歌词                  ← 代码块，可直接复制

---
**话**：选了什么（模板 / 速度量级）+ 改了什么 + 哪里还不满意。
```

**就这些。** 交付纪律（≤5 行、不自证、不主动展开）统一在 `AGENTS.md` 第 4 节，本文件不重复。

### 只有用户问了，才展开这些

| 用户问 | 你给 |
| --- | --- |
| "为什么这么定结构？" | 模板、速度量级及理由、每段几句的理由 |
| "韵怎么押的？" | 韵辙 + 密度（主歌放开几句、放在哪） |
| "用了哪些意象？" | 意象词组矩阵 + 选韵理由 |
| "你自检了吗？" | 只列**没过的项**；全过就一句话 |

⚠️ **不主动交这份「展开」**（`AGENTS.md` 第 4 节）。

## 九、版本化与产出落盘

每首歌一个文件夹，歌词与提示词都放在里面：

```
outputs/{歌曲名}/
  {歌曲名}-lyrics-v1-20261030.md
  {歌曲名}-prompts-v1-20261030.md
  {歌曲名}-lyrics-v2-20261031.md
  ...
```

| 类型 | 文件名 |
| --- | --- |
| 歌词 | `outputs/{歌曲名}/{歌曲名}-lyrics-v{N}-YYYYMMDD.md` |
| 提示词 | `outputs/{歌曲名}/{歌曲名}-prompts-v{N}-YYYYMMDD.md` |

- **首版也写 v1**；歌词与提示词**各自独立递增**，版本号全局唯一，不重置、不回退、不复用
- 日期用**修改当天**（不是首版日期），放最后，同首歌的文件按「类型 + 版本」聚合排序
- 提示词文件头必须写明**对应哪一版歌词**（写路径），对应关系靠文件头表达，不靠文件名
  （不要把歌词版本号嵌进提示词文件名：迭代频率不对称，同一版歌词下可能有 prompts v1–v5，且嵌双版本号会出现两个 "prompts-v1"）
- **绝不覆盖原文件** —— 调整一律生成新文件：用户可能想回退、覆盖后无法 A/B 对比、版本链本身就是创作记录
- 新版本写明：**改了什么**（逐项对照）+ **上一版路径** + **为什么**（详见 `AGENTS.md` 第 4 节）

**顺便**：每轮对话在 `outputs/{歌曲名}/{歌曲名}-log.md` **追加两行**（用户说了什么 / 你做了什么），
追加写、不带版本号。格式见 `references/logging.md`。它不是条件，漏记不判错，
但没有它，换个客户端测试时这边就完全看不到对话。**别把这份记录贴进回复。**

文件头与改动对照表的写法范本见 `examples/002-versioning.md`。
（`outputs/` 不进版本库，skill 里**不要引用**其中的具体文件 —— clone 后必然断链。）
