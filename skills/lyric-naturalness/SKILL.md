# 这段东西是不是歌词

## 为什么要有这一关

实测 7 版，每一版都有画面、有细节、有具体物件、韵脚也压得住。
但没有一版像歌词。

**意象、押韵、金句，都是在"它已经是歌词"的前提上加工的。**
如果连这一步都没过，做得越多，只是在把一段散文打磨得更精致。

这份文档只做一件事：**判定。** 判定不过，回 `lyric-zh` 重写那几句——
不要在这里加工，在一段散文上做意象加工，得到的是一段"有诗意的散文"。

## 判定之前：这话是谁说的

有一类比"散文句"更早失败的东西——**它连"话"都不是**。

```
我把你置顶取消了，又置回去
"对方正在输入"闪了一下又没了
下午三点斜进地铁口的那种
```

三句读起来都通顺，**下面三条判定也挡不住它们**。但没有一句像歌词，因为它们是三种**记录**：

| 句子 | 是什么 | 为什么不是话 |
| --- | --- | --- |
| 我把你置顶取消了，又置回去 | 操作记录 | 一个动作 + 一个撤销。唱到"取消了"已经停住，"又置回去"是追加的注释 |
| "对方正在输入"闪了一下又没了 | 通知记录 | 它要求歌手把**界面上的一行字念出来**。念标识牌不是唱歌 |
| 下午三点斜进地铁口的那种 | 观察记录 | 它不是一个句子，是一个**定语**。唱到"的那种"要等下一个词，可下一个词不存在 |

**共同点：记录没有嘴。** 三句都指向一个**状态**（取消了／闪没了／斜进来了），
没有一句指向**一个人在做什么、看见了什么**。

**判据（一句话）**：这句是"一个人在那一刻说的"，还是"一条提示"？

> 界面、通知、参数都可以当**素材**（微信置顶、已读不回、十二点零七分），
> 但它们**不能当句子的主角**。
> `屏幕暗下去` 可以 —— 那是人在看着它暗；
> `"对方正在输入"闪了一下` 不行 —— 那是一行字在闪。
> 区别：前者是场景里的一个东西，后者是一串字符串。

### 还有一层：机关要拆掉再写

三句都有**机关**：取消又置回（反转）、闪了一下又没了（拟人）、下午三点斜进地铁口（陌生化）。

**机关的作用是让你注意到句子本身；歌词句的作用是让你看见那件事。**
所以机关句读起来像文案、像段子、像广告语——它们都在表演聪明。

**判据**：把机关拆掉，还剩什么？
- 还剩一个处境、一件东西 → 写它，机关可以不要
- 什么都不剩 → 那句本来就只是那句巧话

## 三条判定

三条全过才是歌词。任何一条不过，**这一段还不成立**——不是"不够好"，是"还不是歌词"。

### 1. 一句只有一个人在做事，且只做一件事

数一句里有几个施动者、几件事。

| 句子 | 判定 |
| --- | --- |
| `七点半 我们守在电视机前` | ✅ 一个施动者，一件事 |
| `你说有雨 我把伞忘在教室里面` | ❌ 两个施动者（你 / 我） |
| `你把我拽到屋檐` | ✅ 一个施动者（"我"是宾语，不另算） |
| `结果真下了 你把我拽到屋檐` | ❌ 两件事（下雨 / 拽人） |
| `抬头看天 又看我的脸` | ✅ 一个人，两个连续动作，同一条动作链 |

**一句里出现两个以上"我 / 你"，基本就是这一条没过。**

### 2. 没有一个词在解释关系

查这几组词：

- **因果**：因为 / 所以 / 结果 / 于是
- **时间起算**：从此 / 从那天起 / 后来 / 那一刻

它们出现，说明你在交代一件事的来龙去脉，不是在写歌词。

```
结果真下了 你把我拽到屋檐     ❌ 有"结果"
从那天起 你看天 也看我这张脸    ❌ 有"从那天起"
真下了 拽到屋檐                ✅
```

歌词里的两句是**并排站着**的，不是一句话推导出另一句、也不是"从那以后故事就变了"。

### 3. 末句不是在下结论

看每段最后一句：它给的是画面、动作，还是一个判断？

| 末句 | 类型 | 判定 |
| --- | --- | --- |
| `记得带伞 说不定` | 画面 | ✅ |
| `我早该放手` | 结论 | ❌ |
| `原来你一直在` | 结论 | ❌ |
| `柜门关上了` | 动作 | ✅ |

判据是词：**明白 / 终于 / 原来 / 其实 / 应该 / 值得 / 早该**。
出现任何一个，这段的末句就在替听众下结论。

## 一个对照

同一段主歌，两个版本。

```
初稿
七点半 我们守在电视机前        ①✅ ②✅ ③—
你说有雨 我把伞忘在教室里面    ①❌ 两个施动者
结果真下了 你把我拽到屋檐      ①❌ ②❌ 有"结果"
从那天起 你看天 也看我这张脸   ②❌ 有"从那天起"
```

四条里三条不过。它读起来不差，甚至比很多口水歌工整——**但它是叙述，不是歌词。**

```
定稿
七点半的电视 播着明天          ①✅ ②✅
只说不会下雨 没有争辩          ①✅ ②✅
放学把校服 撑成屋檐            ①✅ ②✅
抬头看天 又看我的脸            ①✅ ②✅（一个施动者，两个动作）
```

**内容几乎一样**：七点半、电视、下雨、伞、屋檐、看脸。
差的是每一句里站着几个人。

## 判定之后

- **第一关就不过**（是记录/机关句）→ 这句不是"改一两字"能救的：**拆掉机关，回到"谁在做什么"**
- **三条全过** → 它是歌词。往下谈意象、韵脚、金句才有意义
- **任何一条不过** → 回 `lyric-zh` 重写**那几句**，不是改字
  - 一句两个施动者 → 删掉一个主语，或把其中一件事挪到下一句
  - 有解释词 → 删掉那个词，看两句还能不能站在一起
  - 末句是结论 → 删掉它，或者换成那个动作本身

⚠️ 不要用"这段读起来还行"来代替判定——那是印象，不是证据。你连续 7 版都这么觉得。
