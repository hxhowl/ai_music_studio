# 歌词自然度：去 AI 味

## 病理：AI 味 = 平均化

AI 写的是**所有人感受的统计平均**，真人写的是**某个具体的人在某个具体时刻**。

所以堆形容词、堆通用意象、对仗完美 —— 这些都不是错，是症状。真正的病是：

> **这句歌词放进任何一首歌都成立，那它就不属于这首歌。**

**总判据**：一段里有没有一个细节是别人写不出来的？没有，就是平均化的。

---

## 七条法则

### 1. 事实优先 —— 可拍照的细节，但**必须成链，不能成堆**

每段主歌**至少 3 个"能被镜头拍到"**的具体名词或动作 —— 这是**下限，不是目标**。

- ❌ "我独自徘徊在深夜" —— 拍不到"独自"，也拍不到"徘徊"
- ✅ "凌晨一点的便利店，我买了两份关东煮" —— 时间、地点、物件、数量，全能拍

#### ⚠️ 实测踩过的坑：凑数凑成流水账（2026-10-31《疯狂动物园》）

v1 的主歌是这样写的：

```
周五 电梯停在十二层 / 工牌没摘 瘫在床垫正中 / 手机七格电 屏幕朝下 /
楼上装修 电钻终于停了 / 外卖盒没扔 还剩半盒 / 闭上眼 风扇转成一团嗡
```

**六个细节，每一个都"可拍照"，每一个都合格，但读起来是分镜表，不是歌词。**
病根正是照着"每段 ≥3 个具象名词"去凑数——凑数最快的方式，就是一行塞一个名词。
（当时模型自己诊断的原话："按'每段 ≥3 个具象名词'凑细节，写成了分镜表，不是一条动作链。"）

**所以：细节要成链，不要成堆。**

| 要求 | 说明 |
| --- | --- |
| 每句承接上一句 | 动作接续（推门 → 灯亮 → 坐到床沿）／因果／一个镜头往前推进 |
| 末句完成一个动作或转折 | 一段要"走到某处"，不是"摆了六样东西" |
| **抽句测试** | 抽掉任意一句，下一句还接得上吗？接得上 = 本来就没承接 = 流水账 |
| **主语测试** | 写出每句的主语：6 句 6 个互不相干的主语 = 清单；同一条线上推进 = 链 |

- ❌ 电梯 / 工牌 / 手机 / 电钻 / 外卖盒 / 风扇 —— 六个并列镜头，抽掉谁都不影响
- ✅ 电梯停在十二层 → 楼道声控灯亮得有点冷 → 工牌懒得摘硌得脖子疼 →
  躺在床沿发愣 → 窗外笑声 → 风扇把我转进梦 —— 一条"回家倒下"的动作链

**操作**：写完一段，把每句的**主语和动词**圈出来。
如果排出来是"物件 A。物件 B。物件 C"，重写成链——不是删细节，是把它们串起来。

#### 更进一步：关键物件要**自己发生变化**，不是每段换一个新物件

成链管的是"句与句",这一条管的是"同一个物件在全首里走没走一条线"。

实测里做得最好的一次（《疯狂动物园》v1）是"工牌"：

| 位置 | 状态 | 承担的叙事 |
| --- | --- | --- |
| 主歌 | `工牌没摘 瘫在床垫正中` | 身体下班了，脑子还挂着 |
| 副歌 | `狮子把我的工牌嚼烂` | 梦替他把身份卸掉了 |
| 尾奏 | `摸了摸脖子 工牌还在` | 醒来发现还在——梦没解决任何事 |

**一个物件串起整首歌的立意。**如果换成三段各写一个新的物件
（工牌 / 爆米花 / 闹钟），每段单独看都合格，但全歌没有主线。

判据：**全首至少有一个物件出现 ≥ 2 次，且第二次出现时状态已经改变**
（没摘 → 被嚼烂 → 还在）。只出现一次、或重复出现但没变化的物件，是装饰不是线索。

### 2. 具体限定 —— 意象必须有专属定语

"风、雨、月、海、落叶"本身没错，错在它们没有专属于这首歌的限定。

- ❌ "雨打湿了我的脸"
- ✅ "台风天把伞吹翻的那种雨"

**判据**：这个意象换到另一首歌里还成立吗？成立就是没限定。

### 3. 制造毛边 —— 打破对称

AI 天然倾向于写等长句。真人写词有呼吸。

- **句长错落**：段落内不要每句字数（音节数）都一样
- **句数不整**：段落之间句数不必整齐划一（主歌 4 / 预副歌 3 / 副歌 6 就很好）
  ⚠️ 毛边是**在句数下限之上做变化**，不是突破下限——
  副歌堆积型仍要 ≥ 6 句，不要为了"不整齐"把副歌压到 3 句（那会伤信息量）
- **允许破韵**：全首留 1 处口语化收尾或破韵，反而更真
- **加一句口语**："想了想，还是没进去" 这类半句话

⚠️ 与 `lyric-zh` 的"字数对齐"不冲突：对齐是**下限**（不能乱到唱不了），毛边是**上限**（不能齐到假）。控制在 ±2 字内做变化。

### 4. 克制呈现 —— show, don't tell

**情绪越重，用词越轻。**

- ❌ "我多么想你，想你想到流泪"
- ✅ "你的牙刷还在杯子里，我买了新的，一直没拆"

第二版一个情绪词都没有，但更痛 —— 因为听众自己会算这笔账。

### 5. 时代标记 —— 当代生活物件 ≥ 1

全首至少出现一个**这个时代才有的具体东西**：电量 12%、外卖备注、已读不回、快递柜取件码、屏幕使用时间、末班车。

AI 写的歌词常常"无时代"—— 放在 1990 年和 2026 年都成立。真人写的是现在。

### 6. 私人口吻 —— 一句"只有他会这么说"的话

全首至少有一句**不像歌词的话**：一句台词、一个口头禅、一个具体到不合常理的细节。

- "你以前总说，我不该吃宵夜"
- "买了两份，第二份第二天吃"

这是去 AI 味**最有效的一招**。它无法被统计平均出来。

⚠️ **这一招优先级高于所有形式指标**（字数对齐、韵脚、句数整齐）。
改词时不得为了凑韵律或字数去改它——实测已经发生过一次：一句"我说 哥 周一还得交周报"
被改成"我烦恼 周一汇报还得交"，只为凑 AABB，而原句本来就在韵上。
**要动它，必须说明理由；写不出理由就不动。**

### 7. 留白 —— 不要把话说满

- 不解释自己的情绪（一旦解释，就变说明文）
- 最后一句可以不说完
- 副歌可以只给画面，不给结论

❌ "我想念你，因为你已经离开" —— 解释完了，没有余味
✅ "快递柜的取件码，我还留着" —— 不说为什么，听众自己补

## Before / After · 中文

### 例 1 · 抽象 → 具体

**AI 味**
```
深夜里我独自徘徊
孤独像潮水般涌来
回忆在心头蔓延开
却找不到你的存在
```
> 四句全是抽象名词（孤独、回忆、心头、存在）+ 陈词比喻（潮水般涌来），且 7/7/7/7 完全对称。

**改后**
```
凌晨一点的便利店
我买了两份关东煮
第二份塞进包里 到早上还是温的
你以前总说 我不该吃宵夜
```
> 具体时间、具体物件、具体动作、具体数量。最后一句是"只有这个人会说的话"——平均化生产不出来。
>
> **句间关系**（这条比"用了什么技巧"重要）：便利店 →（动作）买两份 →（递进）第二份留到早上
> →（转折）"你以前总说"突然拽出一个人。前三句在铺一个习惯，第四句把这个习惯变成了想念。

### 例 2 · 对称 → 毛边

**AI 味**
```
风吹过寂静的长街
雨打湿寂寞的黑夜
月照亮孤独的心扉
谁听见我的叹息
```
> "自然物 + 动词 + 抽象名词"四连排。这是 AI 最爱的模板，因为最好押最好齐。

**改后**
```
风把便利店招牌吹得晃了一下
我站在门口 想了想 还是没进去
手机里那条消息 打了又删
最后发出去的 是早点睡
```
> 句长 15/13/11/10 递减；有动作链（站、想、没进去、打、删、发）；有一句半截话（"想了想"）。

### 例 3 · 直说 → 克制

**AI 味**
```
我多么想你 想你想到流泪
没有你的日子 我快要崩溃
求你回到我身边 别让我心碎
```
> 全是大词直给。情绪强度靠音量，不靠内容。

**改后**
```
你的牙刷还在杯子里
我买了新的 一直没拆
购物车那双鞋 你说秋天要买
现在秋天到了 我没删
```
> 只列物件，零情绪词。但"买了新的没拆"和"秋天到了没删"两处动作，把"放不下"说透了。

### 例 4 · 并列罗列 → 有生长关系（**最重要的一组，直接对应"流水账"**）

**AI 味 —— 物件平铺**
```
周五 电梯停在十二层
工牌没摘 瘫在床垫正中
手机七格电 屏幕朝下
外卖盒没扔 还剩半盒
风扇转成一团嗡
```
> 五句全都"可拍照"，全都符合"具体细节"的要求。**但抽掉任意一句，剩下四句照样成立** ——
> 它们的关系只能被描述为"都是在写回家以后的状态"。没有生长关系的细节，就是清单。
> （这就是 2026-10-31《疯狂动物园》v1 的真实输出。）

**改后 —— 动作链 + 一个物件走完一条线**
```
电梯停在十二层
楼道声控灯 亮得有点冷
工牌懒得摘 硌得脖子疼
只想静静 躺在床沿发愣
风扇转啊转 把我转进梦
```
> **句间关系**：电梯停 →（因果）灯才亮 →（动作接续）工牌硌得疼所以懒得摘
> →（递进）躺下发愣 →（转折收束）风扇把人转进梦。
> 抽掉第 3 句，第 4 句"只想静静"就没有来由 —— **这就是生长关系**，不是修辞。
>
> 物件也承担了功能：这一段里"工牌"从"硌得疼"开始，到副歌被狮子嚼烂、到尾奏"还在"，
> 三次出现状态各不相同（见法则 1）。

### 例 5 · 副歌是主歌的答案，不是另一个话题

**AI 味 —— 副歌换了话题**
```
（主歌）电梯停在十二层 / 工牌没摘 / 手机只剩七格电 / 风扇转成一团嗡
（副歌）这座城市有多少人 / 和我一样 醒着到天明 / 谁的青春不迷茫
```
> 主歌是"我"，副歌突然变成"有多少人""谁的青春"——**话题换了，情绪没接上**。
> 副歌成了另一段描写，而不是主歌憋出来的那句话。
> 典型症状：副歌里出现"我们""多少人""谁的"这类**泛指**，主歌却是具体的"我"。

**改后 —— 副歌是被主歌逼出来的**
```
（主歌）电梯停在十二层 / 楼道声控灯 亮得有点冷 / 工牌懒得摘 硌得脖子疼 / 风扇转啊转 把我转进梦
（副歌）这是不是个动物园 / 动物排队去上班 / 长颈鹿穿着衬衫 / 天亮之前 让我再演一遍
```
> **句间关系**：主歌把"累"一路堆到"被风扇转进梦"——梦成了唯一的出口，
> 那副歌顺理成章就**该是那个梦**。不是换话题，是终于憋不住的那句话。
> 判据很简单：**把主歌最后一句遮住，副歌还显得必然吗？** 不必然就说明它是另起一段。

## Before / After · English

### 例 1 · Perfect rhyme + abstract nouns

**AI**
```
In the darkness I walk alone
Loneliness cuts me to the bone
Memories of you still remain
Nothing can heal this endless pain
```
> perfect rhyme (alone/bone, remain/pain) + 抽象名词堆砌 + "cuts me to the bone" 陈词。

**After**
```
It's 2am and the laundromat's still open
I fold your hoodie last, every time
I keep meaning to give it back
I keep not doing that
```
> 具体时间地点；一个反常的动作顺序（把你的衣服留到最后叠）；"I keep meaning to / I keep not doing" 的重复结构，是真人说话的样子。

### 例 2 · Show, don't tell

**AI**
```
Every day I think of you
Every night I miss you too
Can't you see my heart is true
Tell me what I have to do
```
> 完美 AABB，四句全在直说同一件事。

**After**
```
I still have your Netflix password
I still use it, which is worse
I watched the show you hated
just to see if I'd hate it too
```
> 用一个具体事实承载全部情绪。"which is worse" 是自我吐槽 —— 真人才会这么写，AI 不会主动贬低自己。

### 例 3 · Break the symmetry

**AI**
```
The rain falls down upon my face
I wander through this empty place
Your memory I can't erase
I'm running in a hopeless race
```
> 每句 8 音节，完美 AABB，四句同义反复。

**After**
```
Rain
not the cinematic kind, just the kind that ruins shoes
I'm standing outside your building
for the fourth time this month
which is three more than I'd ever admit
```
> 句长 1 / 12 / 7 / 6 / 9，完全不齐。"not the cinematic kind" 是自我修正，"three more than I'd ever admit" 是具体到不合常理的数字 —— 这两处最像人。

## 诊断表 · 整体弧线 —— **卡壳时先查这里**

> 这一节和下面那份清单都**不是交付门槛**，是**工具箱**。
> 写顺了不用看；觉得"哪里不对但说不上来"时才来翻。
> 门槛只有五条（标签 / 排版 / 版本化 / 结构自洽 / 能唱），见 `lyric-zh` 第七节开头。

查的是"这是不是一首歌"，不是"这些句子合不合格"。

- [ ] **叙事线**：从第一句到最后一句，有一条**情感变化轨迹**。
      ⚠️ 场景变化 ≠ 情感变化——从客厅写到地铁站，情感没动，就是没有弧线。
      同一场景里情感推进也算（烦躁 → 认命 → 一点轻松）。
- [ ] **句间关系**：随机抽 3 处相邻句，每处都要能说出它们的关系
      （**因果 / 递进 / 转折 / 对比**）。如果只能说"都是在描写 X"，这段有问题。
- [ ] **副歌的必然性**：副歌的情绪是**从主歌逼出来的**吗？
      不是换了个话题，而是"终于憋不住了"——副歌该是主歌的答案或爆发，不是另一段描写。
- [ ] **每段末句比首句走得更远** —— 一段之内也有微弧线，不能原地转圈。

> 这四条来自一次外部诊断（2026-10-31），与本项目实测出的"流水账"病根指向同一处：
> **问题从来不在单句写得对不对，在句与句、段与段之间有没有生长关系。**

---

## 诊断表 · 逐句（**卡壳时才查，不是交付门槛**）

- [ ] 全首抽象情绪词 ≤ 3 个，且没有连续出现
- [ ] 每段主歌 ≥ 3 个"可拍照"的细节（**下限**，不是越多越好）
- [ ] **细节成链不成堆**：每句承接上一句，末句完成一个动作或转折
      —— 过一遍法则 1 的**抽句测试 / 主语测试**；排出来是"物件 A。物件 B。物件 C"就是流水账
- [ ] 全首 ≥ 1 个当代生活物件（时代标记）
- [ ] 全首 ≥ 1 句"只有这个人会说"的话
- [ ] 所有通用意象（风/雨/月/海）都加了具体限定
- [ ] 段落内句长有变化，不是每句等长
- [ ] 没有为押韵而倒装的句子
- [ ] 情绪最强的地方，用词是最克制的
- [ ] 每段都提供了新信息，不是换个说法重复
- [ ] 念一遍：有没有哪句是平时说话不会这么说的

**这份表没有及格线。** 它不是考试，是工具箱——查出什么就改什么，改不动就放过。
要说优先级：**第 4 项（私人口吻）是最值钱的一条**，缺了它这首歌谁都能写；
但它**不判不合格**，它只是"这里最值得改"的信号。

## 改写流程

```
① 标记  通读，圈出：抽象词 / 无定限意象 / 等长句 / 陈词比喻
② 定位  判断病型：没细节？细节不对？还是太整齐？
③ 替换  用 references/anti-ai-lexicon.md 的对照表换成具象
④ 打破  调句长、加一句半截话、允许一处破韵
⑤ 补私货  加一句具体台词或反常细节（第 6 条法则）
⑥ 复检  过一遍检测清单
```

**定向原则**：用户说"这段太 AI"，只改这段。但改完要**重读上下文**——具象化之后，前后段的意象密度要匹配，否则会一段真、一段假。
