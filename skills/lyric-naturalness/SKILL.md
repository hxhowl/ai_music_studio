# 让歌词像人说的

## 前提：你判断不了自己写得自然不自然

实测过的 7 版，每一版都自检通过，每一版用户都不满意。
有两次你还写了整段理由论证自己改得好，而那两处正是被改坏的。

所以这份文档**不给判断标准**。它给五个动作。

每个动作产出一版。你要做的不是判断"哪版更自然"，是**把两版并排，问哪一版更像一个人真的会这么说**。
判断需要一套标准，而标准永远不全；比较只需要问一句：**这句话我自己会不会这么说？**

**唯一的判据**：这句话，换一个人说，还成立吗？
成立 → 还是平均化的。不成立 → 它属于这个人。

---

## 一、写之前：钉死谁在说话

不是"写一对青梅竹马"，是四件事：

| 问 | 不能这么答 | 要这么答 |
| --- | --- | --- |
| 这个人是谁 | 一对情侣 | 三十岁，刚被裁员，对方是唯一还联系的人 |
| 他在对谁说 | 对恋人 | 对方不在场——这些话他一句都没说出口 |
| 什么时候 | 深夜 | 分手三个月后，收拾东西的那个下午 |
| **说完想干什么** | 表达思念 | 想让自己相信"我早就放下了" |

**第四问决定语气。** 同一件事：想说服对方、想说服自己、什么都不图只是说出来——三种说法完全不同。
没有第四问，写出来的一定是"作者在描述一段感情"，而不是"一个人在说话"。

**再加一句锚句**：这个人真的会说的话（是话，不是歌词）。

- ✅ `我会假装说 还行` —— 这是话
- ❌ `我强颜欢笑 说我没事` —— 这是歌词

> 锚句写不出来 = 你还没找到这个人。不要往下写。

## 二、五个变换

写完一段，五个动作各做一遍。每个都产出新版，**不一定要采用**。

### 1. 删主语

把"我 / 你"删掉，动词留下。

```
我买了两份关东煮      → 买了两份关东煮
我买了新的 一直没拆    → 新的买了 一直没拆
```

- 删完还读得通 → 用删过的
- 删完读不通 → 那句里关系本身就是内容（`你是我最准的天气预报`），留着
- **一句里两个以上"我 / 你"，基本就是散文句**

### 2. 删交代

删掉"结果 / 因为 / 于是 / 从那天起 / 原来"。

```
结果真下了 你把我拽到屋檐   → 真下了 拽到屋檐
```

删完两句还能站在一起 → 它们本来就不需要连接。
站不住 → 说明你在讲故事，不在写歌。

### 3. 并句

两行合成一行，中间不留连接词。

```
十一点 我坐在楼梯间    → 十一点 楼梯间
手机只剩三格电             手机三格电
```

并完太挤 → 这两件事本来就该分开，别硬并。

### 4. 删到不能再删

每段做三遍删：**删末句**、**删并列里最弱的那个**、**删解释性的半句**。

```
我把伞收进柜子          → （删掉——它在总结）
天气预报说 明天放晴
你说 收着吧 说不定
```

六件事并排的时候，删到只剩三件。**剩下的三件会自己显出关系**——不需要你加因果。

段落最后一句常常是在**总结**，而总结把余味说没了。

### 5. 把镜头挪开

删完主语，如果整段还是"人在做某事"，把镜头从人身上挪到现场的东西上。

```
守在电视机前       → 电视 播着明天
端着面 站在门边     → 一碗面 还冒着白烟
```

判据：镜头里的主角不是"他"，是**那个房间**。

## 三、两个短例

看动作，**不要当模板**——你的题材和这个不一样。

**删主语**，四句上的效果：

```
初稿
七点半 我们守在电视机前
你说有雨 我把伞忘在教室里面
结果真下了 你把我拽到屋檐
从那天起 你看天 也看我这张脸

删主语
七点半 守在电视机前
说有雨 伞忘在教室里
真下了 拽到屋檐
你看天 也看我这张脸
```

删掉六个主语。第四句的"你"留着——"你看天 也看我这张脸"里两个人在对视，**关系本身就是内容**。

**把镜头挪开**：

```
端着面 站在门边        → 一碗面 还冒着白烟
我把伞收进柜子          → 柜门关上了
```

## 四、这五个动作能到什么程度

**它们只能把你从"作文"里拉出来，不能把你送到"好"。**

删完主语和交代之后，剩下的东西会露出来：
- 如果剩下的是"人在做某事"——说明"谁在说话"没钉死，回去补第四问
- 如果剩下的是几个画面——可以了，这就是起点
- 如果剩下的是空的（删完没东西了）——原来那几句本来就只有交代，没有内容

真正好的句子，是从"这个人会怎么说"来的，不是从变换来的。
变换的作用是**把挡住它的东西拿掉**，让那句话露出来。

---

## 五、什么时候停

- **写顺了就不做这套。** 五个变换是卡住时用的，不是交付流程
- 做完之后每段应该**更短、主语更少**。没有变化 = 你可能只是在改词，没动句子
- ⚠️ 别删过头：一句要有内容，删到只剩名词就唱不了了
- ⚠️ 不要为了"像歌词"去堆断片。**断片是删出来的，不是加出来的**
