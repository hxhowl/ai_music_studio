# 这句够不够凝练

## 这份文件管什么

**只管一件事：字有没有多出来。**

不管：好不好、有没有意境、是不是金句——那些没有判据，问了也答不出。
也不管押韵、结构、句数——那些归 `lyric-zh`。

**唯一的动作是删。** 不对清单，不打分，不数句子里有几个人。

---

## 为什么这里不给判据

那些看起来能当判据的东西——**一句几个施动者、有没有因果词、末句是不是结论**——都定不了好坏：

| 好词 | 会被判错的地方 |
| --- | --- |
| `我送你离开 千里之外` | 两个施动者（我送 / 你离开） |
| `天青色等烟雨 而我在等你` | 两个施动者（天 / 我） |
| `越过山丘 虽然已白了头` | 一个人两件事（越过 / 已白头） |
| `因为爱情 不会轻易悲伤` | 有因果词"因为" |

**数量、词性、句法都不能定好坏：**

- 一件事可以拆到两句里：`我送你离开／千里之外`
- 两个人可以在一句里：`天青色等烟雨 而我在等你`——它写的是**一段关系**，不是两件事
- 因果词可以是内容本身：`因为爱情` 里的"因为"删不掉

所以这里不给判据。**判据会让写的人去凑判据，而不是写好那句。**

---

## 唯一的动作：删

逐字、逐词删一遍，每次问：**删掉它，损失了什么？**

- 损失了一件具体的东西 → 这个字在干活，留
- 什么都不损失 → 它在凑数，删

三个常见的"多出来的字"。**它们是气味，不是规则**，闻到才查：

1. **同义重复** —— `我很孤单 没有人陪`：两句说的是同一件事，删一句
2. **替听众连因果** —— 因为 / 所以 / 结果 / 于是：多数时候在把两句话粘起来。
   ⚠️ 但 `因为爱情` 里的"因为"删不掉——它本身是这句话的内容
3. **评价性的修饰** —— 深深地 / 无比 / 那样 / 真的很：形容词和程度副词在替读者下判断

判断的都是"这一句"，不是"这一段够不够三个"。**凑数就是这里最容易犯的错。**

---

## 删不掉的三种：连话都不是

这三种不用删，因为删完什么都不剩——**要重写**。

```
我把你置顶取消了，又置回去
"对方正在输入"闪了一下又没了
下午三点斜进地铁口的那种
```

| 句子 | 是什么 | 为什么不是话 |
| --- | --- | --- |
| 我把你置顶取消了，又置回去 | **操作记录** | 一个动作 + 一个撤销。唱到"取消了"已经停住，"又置回去"是追加的注释 |
| "对方正在输入"闪了一下又没了 | **通知记录** | 要求歌手把**界面上的一行字念出来**。念标识牌不是唱歌 |
| 下午三点斜进地铁口的那种 | **观察记录** | 不是句子，是定语。唱到"的那种"要等下一个词，可下一个词不存在 |

**共同点：记录没有嘴。** 三句都指向一个**状态**（取消了／闪没了／斜进来了），
没有一句指向**一个人在做什么、看见了什么**。

问一句：**这句是"一个人在那一刻说的"，还是"一条提示"？**

> 界面、通知、参数都可以当**素材**（微信置顶、已读不回、十二点零七分），
> 但它们**不能当句子的主角**。
> `屏幕暗下去` 可以 —— 人在看着它暗，它是场景里的一个东西；
> `"对方正在输入"闪了一下` 不行 —— 那是一串字符串在闪。
> **唱一句引号里的字，等于念标识牌。**

---

## 还有一层：机关

三句还有同一个味道——**都在耍聪明**：
取消又置回（反转）、闪了一下又没了（拟人）、下午三点斜进地铁口（陌生化）。

> **机关让你注意到句子本身；歌词句让你看见那件事。**

所以机关句读起来像文案、像段子、像广告语。它们都有"设计感"。

**动作**：把机关拆掉，看还剩什么。
- 还剩一个处境、一件东西 → 写它，机关可以不要
- 什么都不剩 → 那句本来就只是那句巧话

---

## 停手

删到删不动了，就停。**不要继续磨那句"能不能更好"**——
那是没有底的，而且你判断不了（7 版实测，每一版都自评通过，每一版都不满意）。

一句话自检：**这遍删完，有没有哪句变短了但意思没变？** 没有就收工。
