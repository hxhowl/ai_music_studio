# 歌曲生成提示词构建

## 核心认知

**Suno 和秒响要的不是同一种东西。** 同一首歌，在两个平台的提示词形态完全不同，不能互译。

| | **Suno** | **秒响 Sway** |
| --- | --- | --- |
| 形态 | 逗号分隔的**英文标签串** | **中文长句**自然语言描述 |
| 优化目标 | 标签密度 + 互斥性 | 人声细节 + 演唱处理 + 段落指令 |
| 长度 | Style 字段 ≤ 200 字符，≤ 15 个标签 | 不限，越具体越稳 |
| 人声 | `female vocals, breathy, ethereal` | "成年女声，气声为主，咬字轻，句尾收音干净" |
| 结构 | 靠歌词里的 `[Chorus]` 等标签 | 提示词里可直接描述段落安排 |
| 负面 | `Exclude Styles` 字段 | 中文里写"不要 XX" |

> ⚠️ 把英文标签直译成中文丢给秒响 → 塌。把秒响长句压成标签塞给 Suno → 糊。各写各的。

---

## 流程

### 第 1 步：九维定参

逐项定下来。用户没说的给**推荐值并标注**，不要留空。

| # | 维度 | 说明 | 例 |
| --- | --- | --- | --- |
| ① | **曲风/流派** | 主风格 1 个 + 辅助 ≤1 个 | city pop（+ R&B） |
| ② | **情绪氛围** | 具体可感知，带场景；**裸情绪词 ≤ 2 个** | 清冷孤独，尾段透出一点希望 |
| ③ | **核心乐器** | **只点 3–5 件，每件带演奏法或器材** | 呢垫电钢琴、闷音立式贝斯、brush 军鼓、室内乐弦乐 |
| ④ | **节奏速度** | BPM 或律动描述 | 85 BPM，laid-back |
| ⑤ | **调性** | 大调/小调；不确定就不写 | A 小调 |
| ⑥ | **人声** | 性别、音区、音色、语言、**唱法** | 女声，中低音区，气声，普通话，近独白 |
| ⑦ | **制作质感**（必填） | 年代 + 录音方式 + 空间，**三选二** | 70s 磁带饱和，单麦同期，短房间混响 |
| ⑧ | **编曲事件**（必填，最易漏） | **至少 1 条时间轴指令** | 前 12 秒纯电钢琴；桥段抽掉鼓留 4 秒纯人声 |
| ⑨ | **结构指令** | 段落安排 | 双副歌 + 桥段，第二段副歌后加器乐桥段 |

**冲突检查**：定完九维后扫一遍有没有自相矛盾（"fast lo-fi"、"intimate arena rock"）。有就让用户二选一。

### 第 1.5 步：反套路红线（差异化硬约束）

**同质化的根因是"安全词组合"**——`dreamy ethereal melancholic` 这类词被用烂，模型响应已收敛到平均值。写进去等于没写。

定完九维后，逐条自查。细则与替换词表见 **`skills/production-antislop/SKILL.md`**。

| # | 红线 | 要求 |
| --- | --- | --- |
| 1 | **去安全词** | 裸情绪词 ≤ 2 个，且带场景限定；`dreamy` `ethereal` `beautiful` `emotional` `catchy` 等黑名单词汇必须替换 |
| 2 | **有事件** | ≥ 1 条时间轴指令。**Suno 用歌词结构标签承载，秒响直接写长句**——不要把长句塞进 Suno 的 Style 字段 |
| 3 | **有锚点** | ≥ 1 个专属锚点：反差音色 / 演奏法器材 / 质感设定，三选一（反差最强） |
| 4 | **有质感** | ⑦ 必填，年代 / 录音方式 / 空间至少两项 |
| 5 | **乐器带演奏法** | 不出现裸类别名（`piano` `drums` `strings` 单独出现即为不合格） |
| 6 | **Exclude 有针对性** | 排除的是"这个风格最可能的失败形态"，不是随便写几个 |

> **总判据**：换掉提示词里任意一个标签，出来的歌会明显不同吗？不会，就是还没做完这一步。

### 第 2 步：写 Suno 版

**形态**：英文标签串，逗号分隔。

```
{主风格}, {辅助风格}, {情绪1}, {情绪2}, {人声性别} vocals, {音色},
{乐器1}, {乐器2}, {乐器3}, {BPM} BPM, {质感}, {年代/地域}
```

**硬约束**：
- ≤ 15 个标签
- ≤ 200 字符（Style of Music 字段上限约 200）
- 主风格**唯一**，辅助风格最多 1 个
- 乐器 3–5 件，**每件带演奏法或器材**（`brush snare` 而非 `drums`）
- **禁用歌手姓名**代替风格（写"中国风 + R&B + 说唱段落"，不写"像周杰伦"）
- 纯音乐就显式写 `instrumental, no vocals`
- **质感标签必给**（年代 / 录音方式 / 空间，至少两项）

**必给 Exclude Styles**：把不想要的东西写进排除字段，比在正向里堆词有效得多。
要排除的是**这个风格最可能的失败形态**（古风 → `no operatic vocal, no heavy reverb`；抒情 → `no autotune`）。

**编曲事件怎么落**：Style 字段写不下长句，事件分两处承载——

| 载体 | 写法 |
| --- | --- |
| Style 字段 | 只放**动态词**：`sparse intro` `building` `dynamic contrast` `breakdown` |
| **歌词结构标签** | 这才是事件真正的落点：`[Instrumental Break]` `[Breakdown]` `[Drop]` `[Guitar Solo]` `[whisper]` `[falsetto]` |

> ⚠️ 把"副歌前抽掉鼓"写进 Style 字段 → Suno 读不懂。正确写法：Style 给 `dynamic contrast`，歌词里插 `[Breakdown]`。

**歌词侧**：结构靠歌词里的 `[Verse]` `[Chorus]` 等标签（见 `lyric-zh` / `lyric-en`）。

完整标签库见 **`references/suno-tags.md`**；演奏法、质感、反差配方见 **`references/production-lexicon.md`**。

### 第 3 步：写秒响版

**形态**：中文长句，像给一个真人歌手 + 编曲写 brief。

**九要素清单**（按示例抽象，尽量覆盖）：

| # | 要素 | 例 |
| --- | --- | --- |
| 1 | 风格/唱腔 | 京腔化新古风 |
| 2 | 人声性别与音区 | 北方成年男中低音 |
| 3 | 发声方法 | 京剧老生本嗓大嗓，全程胸声实音 |
| 4 | 咬字与字词处理 | 字头硬，喷口短，一字一拍 |
| 5 | 板式/节奏/BPM | 西皮原板板眼，约 129 BPM |
| 6 | 配器 | 板鼓点板，京胡两音短答 |
| 7 | 旋律走向 | 旋律始终在中低音区，句尾同音短反复后下行收住 |
| 8 | 入声时机与段落 | 第 2 秒入声，第二段副歌后留 8 秒纯器乐 |
| 9 | 录音质感 + 完整度 | 录音室近声，完整旋律演唱 |

**写法要点**：
- 用**逗号/分号**分隔要素，形成一整段，不要分点列条
- 人声部分写得越细越好（这是秒响相对 Suno 的优势区）
- 可以直接给**旋律走向**与**句尾处理**这类微观指令
- 不想要的直接写"不要 XX"
- **时间轴指令直接写中文**，这是秒响相对 Suno 最大的优势："前 12 秒纯电钢琴""桥段抽掉鼓留 4 秒纯人声"
- **质感必须具体到录制方式**：不写"温暖"，写"单支铝带麦克风同期录制，70 年代磁带饱和"

完整规范与示例见 **`references/platform-miaoxiang.md`**；事件句库见 **`references/production-lexicon.md`** 第五节。

### 第 4 步：双语输出

每个平台**各出中文 + 英文**两份，共 4 段：

1. Suno · 英文标签串（可直接粘贴）
2. Suno · 中文对照说明（解释每个标签在干什么）
3. 秒响 · 中文长句（可直接粘贴）
4. 秒响 · English 对照说明

**关键**：中文说明 ≠ 把英文翻译成中文。它是**给用户的解释**，说清设计意图。

### 第 5 步：附设计说明 + 待确认项

- 九维定参表
- **专属锚点说明**：写明"这首歌区别于同类的是什么"（哪个反差音色 / 哪条编曲事件）
- 标出 1–2 个"最需要试听后确认"的点（通常是 BPM 和人声音色）

## 常见失败与处方

| 症状 | 诊断 | 处方 |
| --- | --- | --- |
| 太素 | 乐器少 / 情绪词笼统 | 加 1–2 件色彩乐器；"清冷"→"凌晨空旷地铁站的清冷" |
| 风格乱 | 标签过多、主风格不唯一 | 砍到 1 主 + 1 辅 |
| 人声出戏 | 缺语言与音色 | 补"普通话、女声、气声、中低音区" |
| 速度不对 | 没写 BPM | 显式给 BPM + 律动描述 |
| 副歌不炸 | 缺能量对比 | 主歌 sparse/intimate ↔ 副歌 anthemic/wall of sound |
| 意外出现人声 | 没声明纯音乐 | 写 `instrumental, no vocals` |
| **都一个样** | 安全词组合、无专属锚点 | 走 `production-antislop`：加反差音色 / 编曲事件 / 具体质感 |
| **事件没生效** | 长句塞进了 Suno Style 字段 | Suno 读不懂长句 → 落歌词结构标签 `[Breakdown]`，Style 里只留 `dynamic contrast` |

**定向调参原则**：只改出问题的那一维，其余不动，方便用户 A/B 对比。

## 自检清单

**基础规范**
- [ ] 中英双语齐全（4 段）
- [ ] Suno 版：标签串、≤15 标签、≤200 字符、无自相矛盾
- [ ] 秒响版：中文长句、含人声与演唱处理
- [ ] 乐器 3–5 件
- [ ] 无歌手姓名
- [ ] 有 Exclude / 负向描述
- [ ] 可直接复制粘贴，无解释混在正文里

**差异化（第 1.5 步红线，详见 `production-antislop`）**
- [ ] 裸情绪词 ≤ 2 个，无安全词黑名单词汇
- [ ] ≥ 1 条编曲事件，且落在正确载体（Suno → 结构标签；秒响 → 长句）
- [ ] **≥ 1 个专属锚点**（反差音色 / 演奏法器材 / 质感设定）——不过关即不合格
- [ ] 质感已填：年代 / 录音方式 / 空间至少两项
- [ ] 乐器全带演奏法或器材，无裸类别名
