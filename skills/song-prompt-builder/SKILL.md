# 歌曲生成提示词构建

## 核心认知

**Suno 和秒响要的不是同一种东西。** 同一首歌，在两个平台的提示词形态完全不同，不能互译。

| | **Suno** | **秒响 Sway** |
| --- | --- | --- |
| 形态 | 逗号分隔的**英文标签串** | **中文长句**自然语言描述 |
| 优化目标 | 标签密度 + 互斥性 | 人声细节 + 演唱处理 + 段落指令 |
| 长度 | Style 字段 ≤ 200 字符，≤ 15 个标签 | 不限，越具体越稳 |
| 人声 | `female vocals, breathy, ethereal` | "成年女声，气声为主，咬字轻，句尾收音干净" |
| 结构 | 靠歌词里的 `[Chorus]` 等标签 | 提示词里可直接描述段落安排 |
| 负面 | `Exclude Styles` 字段 | 中文里写"不要 XX" |

> ⚠️ 把英文标签直译成中文丢给秒响 → 塌。把秒响长句压成标签塞给 Suno → 糊。各写各的。

---

## 流程

### 第 1 步：八维定参

逐项定下来。用户没说的给**推荐值并标注**，不要留空。

| # | 维度 | 说明 | 例 |
| --- | --- | --- | --- |
| ① | **曲风/流派** | 主风格 1 个 + 辅助 ≤1 个 | city pop（+ R&B） |
| ② | **情绪氛围** | 具体可感知，带场景更好 | 清冷孤独，尾段透出一点希望 |
| ③ | **核心乐器** | **只点 3–5 件** | 电钢琴、闷音贝斯、brush 军鼓、弦乐 pad |
| ④ | **节奏速度** | BPM 或律动描述 | 85 BPM，laid-back |
| ⑤ | **调性** | 大调/小调；不确定就不写 | A 小调 |
| ⑥ | **人声** | 性别、音区、音色、语言 | 女声，中低音区，气声，普通话 |
| ⑦ | **制作质感** | 年代感与录音特征 | 录音室近声，轻度磁带饱和 |
| ⑧ | **结构指令** | 段落安排 | 前 15 秒纯氛围引子，第二段副歌后加器乐桥段 |

**冲突检查**：定完八维后扫一遍有没有自相矛盾（"fast lo-fi"、"intimate arena rock"）。有就让用户二选一。

### 第 2 步：写 Suno 版

**形态**：英文标签串，逗号分隔。

```
{主风格}, {辅助风格}, {情绪1}, {情绪2}, {人声性别} vocals, {音色},
{乐器1}, {乐器2}, {乐器3}, {BPM} BPM, {质感}, {年代/地域}
```

**硬约束**：
- ≤ 15 个标签
- ≤ 200 字符（Style of Music 字段上限约 200）
- 主风格**唯一**，辅助风格最多 1 个
- 乐器 3–5 件，不堆砌
- **禁用歌手姓名**代替风格（写"中国风 + R&B + 说唱段落"，不写"像周杰伦"）
- 纯音乐就显式写 `instrumental, no vocals`

**必给 Exclude Styles**：把不想要的东西写进排除字段，比在正向里堆词有效得多。

**歌词侧**：结构靠歌词里的 `[Verse]` `[Chorus]` 等标签（见 `lyric-zh` / `lyric-en`）。

完整标签库见 **`references/suno-tags.md`**。

### 第 3 步：写秒响版

**形态**：中文长句，像给一个真人歌手 + 编曲写 brief。

**九要素清单**（按示例抽象，尽量覆盖）：

| # | 要素 | 例 |
| --- | --- | --- |
| 1 | 风格/唱腔 | 京腔化新古风 |
| 2 | 人声性别与音区 | 北方成年男中低音 |
| 3 | 发声方法 | 京剧老生本嗓大嗓，全程胸声实音 |
| 4 | 咬字与字词处理 | 字头硬，喷口短，一字一拍 |
| 5 | 板式/节奏/BPM | 西皮原板板眼，约 129 BPM |
| 6 | 配器 | 板鼓点板，京胡两音短答 |
| 7 | 旋律走向 | 旋律始终在中低音区，句尾同音短反复后下行收住 |
| 8 | 入声时机与段落 | 第 2 秒入声，第二段副歌后留 8 秒纯器乐 |
| 9 | 录音质感 + 完整度 | 录音室近声，完整旋律演唱 |

**写法要点**：
- 用**逗号/分号**分隔要素，形成一整段，不要分点列条
- 人声部分写得越细越好（这是秒响相对 Suno 的优势区）
- 可以直接给**旋律走向**与**句尾处理**这类微观指令
- 不想要的直接写"不要 XX"

完整规范与示例见 **`references/platform-miaoxiang.md`**。

### 第 4 步：双语输出

每个平台**各出中文 + 英文**两份，共 4 段：

1. Suno · 英文标签串（可直接粘贴）
2. Suno · 中文对照说明（解释每个标签在干什么）
3. 秒响 · 中文长句（可直接粘贴）
4. 秒响 · English 对照说明

**关键**：中文说明 ≠ 把英文翻译成中文。它是**给用户的解释**，说清设计意图。

### 第 5 步：附设计说明 + 待确认项

- 八维定参表
- 标出 1–2 个"最需要试听后确认"的点（通常是 BPM 和人声音色）

## 常见失败与处方

| 症状 | 诊断 | 处方 |
| --- | --- | --- |
| 太素 | 乐器少 / 情绪词笼统 | 加 1–2 件色彩乐器；"清冷"→"凌晨空旷地铁站的清冷" |
| 风格乱 | 标签过多、主风格不唯一 | 砍到 1 主 + 1 辅 |
| 人声出戏 | 缺语言与音色 | 补"普通话、女声、气声、中低音区" |
| 速度不对 | 没写 BPM | 显式给 BPM + 律动描述 |
| 副歌不炸 | 缺能量对比 | 主歌 sparse/intimate ↔ 副歌 anthemic/wall of sound |
| 意外出现人声 | 没声明纯音乐 | 写 `instrumental, no vocals` |

**定向调参原则**：只改出问题的那一维，其余不动，方便用户 A/B 对比。
