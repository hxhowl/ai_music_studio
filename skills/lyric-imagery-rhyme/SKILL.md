# 意象关联词组 × 押韵推荐字

这个 skill 是**素材供给器**，不是代笔。它的产出是让用户可以自己挑选的词组与字表，而不是替用户决定全部用词。

核心立场：**好的意象来自约束，不是来自灵感。** 先锁定场景的物理边界，再在这个边界里找具体的东西。

---

## 模式 A · 意象关联词组

### 触发

- "没有画面感"
- "帮我找一些意象"
- "围绕 XX 主题给我一些词"
- 写词中途缺具象名词

### 生成方法：四步展开

#### 第 1 步：锁定场景边界

意象之所以空洞，是因为没有边界。先问清楚（不知道就给推荐值）：

- **时间**：几点？什么季节？（凌晨三点 ≠ 傍晚六点）
- **空间**：室内/室外？多大？（地铁站 ≠ 卧室）
- **人物状态**：在做什么？一个人吗？
- **物件**：这个场景里**实际存在**的东西有哪些？

> 例：不是"孤独"，而是"凌晨 00:47 的末班地铁，车厢里 3 个人，手机 4% 电"。

#### 第 2 步：按感官维度展开（核心产出）

围绕核心主题，往五个感官通道各铺 3–5 个词组。**视觉之外的通道最容易被忽略，也最有画面感。**

| 维度 | 问什么 | 例（主题：深夜城市） |
| --- | --- | --- |
| **视觉** | 看见什么？什么颜色？什么光？ | 荧光灯频闪、闸机红点、玻璃上的倒影、熄灭的楼宇、塑料袋飘过 |
| **听觉** | 听见什么？远还是近？ | 末班车报站、风穿过通道、高跟鞋回声、自动门"叮"、冰美式里的冰块 |
| **触觉** | 什么温度？什么质地？ | 金属扶手的凉、外套上的夜露、口袋里手机发烫、风灌进领口 |
| **嗅觉/味觉** | 什么气味？ | 消毒水、雨后沥青、便利店关东煮、隔夜烟味、凉掉的黑咖啡 |
| **动作** | 身体在做什么？ | 刷卡、低头系鞋带、数站牌、反复解锁屏幕、把耳机线绕两圈 |

#### 第 3 步：意象簇扩展

对每个核心意象做**三个方向的邻接扩展**：

| 方向 | 说明 | 例（核心：地铁） |
| --- | --- | --- |
| **同类** | 同一语义场的其他词 | 闸机、站牌、屏蔽门、换乘通道、末班车 |
| **通感** | 转换感官通道描述同一事物 | 报站声**发黄**、灯光**有重量**、风**是钝的** |
| **反向** | 这个场景里**不该有**但出现的东西 | 空车厢里的一束花、凌晨的冰淇淋车 |

**通感是高级感的来源**：把听觉写成有颜色，把视觉写成有温度。

#### 第 4 步：淘汰陈词

生成后**主动剔除**以下三类：

| 类型 | 例 | 为什么删 |
| --- | --- | --- |
| 成语/固定搭配 | 繁花落尽、岁月如歌、灯火阑珊 | 已被用烂，无新鲜感 |
| 抽象情绪词 | 孤独、寂寞、忧伤、彷徨 | 不产生画面 |
| 无场景指向的美词 | 星辰、苍穹、流年 | 哪儿都能用 = 哪儿都不属于 |

**替换公式**：抽象词 → 该情绪下**身体会做的具体动作或接触的具体物件**。
- "孤独" → "把外卖备注写成'放门口谢谢'"
- "想念" → "翻到三年前的聊天记录没删"

### 输出格式

```markdown
## 意象词组矩阵 · 主题《XXX》

**场景边界**：时间 / 空间 / 人物状态 / 实际物件

| 维度 | 词组 |
| --- | --- |
| 视觉 | ... |
| 听觉 | ... |
| 触觉 | ... |
| 嗅觉/味觉 | ... |
| 动作 | ... |

**通感可选项**：...
**建议避开**：...
**我推荐的 3 个**：... （说明理由）
```

## 模式 B · 押韵推荐字

### 触发

- "这句押不上"
- "给我一些押 X 韵的字"
- "韵脚太普通了"
- "想换韵"

### B1 · 中文：按十三辙给字

完整字表见 **`references/rhyme-zh.md`**（十三辙 + 常用韵字，按平/仄与词性分组）。

**给字流程**：

1. **确定韵辙**：若用户未指定，按其情绪倾向推荐（见 `lyric-zh` 的选韵原则）
2. **分层给字**，而不是甩一大堆：

| 层级 | 说明 | 目的 |
| --- | --- | --- |
| ① 高频安全字 | 该辙最常用的 10–15 字 | 保底能押 |
| ② 冷门字 | 同辙但少见的字 | 制造新鲜感 |
| ③ 双音词 | 该辙收尾的两字词 | 方便凑句尾节奏 |
| ④ 该辙的"危险字" | 容易写成陈词的字 | 提醒避开 |

3. **标注声调**：平声（一、二声）柔长，仄声（三、四声）有力。说唱/摇滚优先仄声。
4. **给"句尾搭配"**，不只是单字：例如"一七辙"给"没**关系** / 下**雨** / 回**去**"

**示例（由求辙）**：
- 高频：愁 秋 留 手 头 走 久 有 酒 旧 友 楼 流 求 收 够 透 柔 舟
- 冷门：眸 囚 兜 锈 稠 叟 寇 轴 肘
- 双音词：回**头**、以**后**、接**受**、朋**友**、温**柔**、皱**纹**、遗**留**
- 危险字：愁、忧（易陈词）

### B2 · 英文：按韵族给词

完整词表见 **`references/rhyme-en.md`**。

**给词流程**：

1. 确定 rhyme family（-ight / -ay / -ow …）
2. 分三层给：perfect rhyme（10–15 词）→ slant rhyme → multi-syllabic
3. 标注**音节数**，方便对齐 meter
4. 给 phrase-level 搭配，不只单词：例如 "-ay" 给 "walk a**way** / yester**day** / can't **stay**"

### B3 · 换韵建议

用户觉得韵脚不对时，先诊断再换：

| 症状 | 诊断 | 处方 |
| --- | --- | --- |
| 韵字太俗 | 撞上该辙的高频字 | 换辙，或改用该辙冷门字 |
| 押得上但不好听 | 开口度与情绪不匹配 | 按情绪重新选开口度大的/小的辙 |
| 整段绵软 | 多用平声/弱韵 | 换仄声韵或换更硬的辙（江阳、中东） |
| 太工整显得假 | 全 perfect rhyme | 掺 1 处 slant rhyme，制造口语感 |

---

## 组合用法

写词全流程里，本 skill 通常被调用 2–3 次：

```
选韵阶段 → 模式 B（定辙 + 拿字表）
写主歌   → 模式 A（按感官铺画面）
卡壳时   → 模式 A + B（换词 or 换韵）
```

## 产出落盘

不单独落盘，作为歌词交付物的附录（`## 意象与韵脚设计` 一节）写入
`outputs/{歌曲名}/{歌曲名}-lyrics-v{N}-YYYYMMDD.md`。
