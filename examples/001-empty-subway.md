# 示例 ·《空车厢》

> 端到端演示：一句模糊描述 → 歌词 + Suno 提示词 + 秒响提示词。
> 按 `AGENTS.md` 第 3 节的流程（⓪ 锚句 → ③ 先写副歌 → ④ 定结构 → ⑤ 定韵 → ⑥ 主歌 → ⑦ 删）走一遍。
>
> ⚠️ **本例是教学样例，故意把推导过程全部展开**（`AGENTS.md` 第 4 节「交付形态」的例外）。
> 真实交付只有**两样**：歌词 + ≤5 行话。这里中间那些「为什么」是你被问到时才该拿出来的东西。

---

## 用户输入

> "想做一首关于深夜加班后走在空荡地铁站的歌，女生唱，清冷孤独一点，但结尾要有一点点希望。"

---

## ⓪ 定场景 + 锚句

**场景边界**（几点 / 在哪 / 在做什么 / 实际存在什么物件）：

> 凌晨 00:47 · 地下二层末班地铁站 · 一个人等下班的末班车 · 闸机、屏蔽门、站牌、手机、凉掉的咖啡

不是"深夜的孤独"，是"00:47 的地下二层"。这一步决定全首取材——跳过它，写出来的就是放之四海皆准的句子。

**★ 锚句**：`我会假装说 还行`

全首最像人说的就是这句。它后来成了桥段的落点，也是整首歌的情绪核心：不是"我很痛"，是"我不想让你知道"。
**先有它，才有这首歌。**

---

## ① 澄清 + 立意

语言、风格、情绪用户都给了（中文 / 都市抒情 / 清冷转微暖），**不追问**，只把两个模糊处自己定下来、
一句话复述：清冷 = 都市抒情 + dream pop 质感；"一点点希望"= 微暖，不是昂扬。

- **立意一句话**：不是"孤独"本身，而是"发现这座城市睡了，但自己还有一班车的路要走"——疲惫里带着一点不肯熄的劲儿

## ② 定调性

- **情绪弧线**：麻木 → 松动 → 承认脆弱（桥段）→ 微光（尾奏）
- **视角**：第一人称，独白式
- **hook 方向**：从锚句的"假装没事"反推——真正想说的是"空"，所以 hook 用三个"空"字叠

---

## ③ 先写副歌（定靶心）

副歌是主歌的答案。**答案先写出来，才知道主歌要铺哪条路。**

```
空车厢 空站台 空的回声
一个人的脚步声很重
整座城睡了 只有灯还醒
总有一班车 会开往晴空
往前走 出口越来越近
近到能听见 地面的风声
```

写了 6 句，先不说为什么是 6——那是下一步数的。这一步只要确认一件事：
**副歌把"疲惫 → 微光"说清楚了没有？** 说清了（靠"地面的风声"，不靠"会好的"），可以往下走。

> 如果这一步写不出来（比如只剩"我很难过"这种），说明立意还没想清 → 退回 ⓪，
> **不要硬写主歌**。先写主歌的后果是：写 V1 时不知道要抵达哪里，六个镜头并列，那就是流水账。

---

## ④ 定结构（按副歌倒推）

**模板：T1 抒情 ballad** —— 副歌是主体、主歌短副歌长，命中 T1。

相对 T1 基准做了两处微调：Pre-Chorus 2→3 句、Outro 3→4 句。
理由：**T1 是九个模板里最紧凑的一个**，各加一句让它铺得开一点——
PC 3 句的爬升更够，Outro 4 句让渐退不显仓促。

**BPM = 85**，来源：模板典型值（用户没指定，取 T1 典型值并声明）。

> 「依据」列指 `references/song-structure.md` 的小节号。

| 段落 | 句数 | 为什么 | 依据 |
| --- | --- | --- | --- |
| Intro | — | 纯电钢琴引子，只写标签 | — |
| Verse 1 | 4 | 抒情型主歌 ≤ 副歌；4 句够铺一个场景 | 4.5 |
| Pre-Chorus 1 | 3 | 爬升段，短才有推力（T1 基准 2 句，本例 3） | 可选段落表 |
| **Chorus 1** | **6** | 情绪功能 = **堆积**（清冷 → 微光）→ 6 句 | 4.2 |
| Verse 2 | 4 | **与 V1 相等** —— 同旋律，句数必须相等 | 第五节 |
| Pre-Chorus 2 | 3 | 与 PC1 相等（同旋律） | 第五节 |
| **Chorus 2** | **6** | 与 C1 相等（同旋律） | 第五节 |
| Bridge | 4 | 转折，够说清一件事 | — |
| **Chorus 3** | **6** | 与 C1/C2 相等；三次副歌字面一致 | 第五节 |
| Outro | 4 | 渐弱收束（T1 基准 3 句，本例 4） | — |
| **全首** | **40 句** | 30 句正段 + 10 句 PC/Outro | — |

**为什么副歌是 6 句**：这首要"从清冷走到一点点希望"，是**堆积型**——
一句说完就没了，得让情绪踩着台阶往上走。4 句只够一级半。
**为什么不是 8 句**：8 句会让副歌压掉主歌铺的场景；这首靠**三次重复**建立记忆
（同一段副歌出现三遍），不靠变奏加长。

**副歌 6 句的落法**（本例三次字面一致）：

| 句 | 功能 |
| --- | --- |
| 1 | hook 在句首："空车厢 空站台" |
| 2–3 | 展开与推进 |
| 4 | 转折点（从内到外） |
| 5–6 | 落句 / 场景收束 |

> 若要改成"三次变奏递进"，把**第 4 句**写成三次不同即可（6 句里改 1 句 ≈ 17%，hook 最稳）。
> 但那样就不能再声称"三次副歌完全一致"——理由是结构的一部分，得对得上。

**如果后来要求改成 120 BPM**：结构不用重算，**要改的是句子长度**。

- 6 句副歌在 120 BPM 下会显得赶——每句能装的字变少，歌往前冲
- 处理办法是**删字或断句**，让这 6 句唱得完；**不是加句**
- 真觉得情绪还差一口气，可以加一段 `[Post-Chorus]`（那是**新段**，不改副歌句数）
- ⚠️ **不要把这 6 句副歌改成 8 句**——前两次副歌都是 6 句，同旋律句数必须相等（条件 4）

⚠️ 别去算"6 句在 120 BPM 是多少秒"。那个数本来就不准（一句跨不跨小节、有没有长音、
有没有休止都会变），算出来只会让人忍不住去凑。

## ⑤ 定韵（允许事后改）+ 取意象

**韵辙**：中东辙（eng / ing / ong）。

不是先定死再写——是**看副歌自然落在哪个辙**：写出来"回声 / 很重 / 还醒 / 晴空 / 风声"，
本来就压在鼻音上（eng / ing / ong），于是顺水推舟统一到中东辙。它自带冷感，
同时有"声/重/醒/空/灯/程"这一族既有冷调又有光亮面，能承载清冷 → 微暖的转折，不需要换辙。

> **两处刻意的手法，别当错误改**（对照 `lyric-zh` 的重韵表与顶真例外）：
>
> - 预副歌「再等三分钟／再撑三分钟」——**相邻两句同字收尾，但这是排比**：
>   句式完全一样，只把"等"换成"撑"，消极变积极，重复本身在推情绪。
>   判据：去掉尾字后，两句前半截结构一样 → 排比，不是重韵。
> - 副歌第 5 句「出口越来越**近**」落在**人辰辙**（in），**不是破韵，是顶真**——
>   下一句「**近**到能听见 地面的风声」以它的末字开头，得让位。
>   ⚠️ 判据是硬的：下一句真的以"近"开头才算。否则就是普通破韵，按"副歌句句押"算。

**意象词组矩阵**（按 ⓪ 的场景边界取，不越界）：

| 维度 | 词组 |
| --- | --- |
| 视觉 | 闸机红点、熄灭的站牌、玻璃里的倒影、白炽灯频闪、空荡的车厢 |
| 听觉 | 末班车报站、风穿过通道、脚步回声、自动门"叮"、耳机漏音 |
| 触觉 | 金属扶手的凉、凉掉的咖啡杯、外套上的夜露、风灌进领口 |
| 物件 | 手机电量、工牌、便利店白灯、耳机、凉咖啡 |

中东辙常用韵字：空 · 声 · 灯 · 风 · 中 · 城 · 影 · 停 · 懂 · 梦 · 疼 · 冷 · 同 · 通 · 红 · 动 · 松 · 终 · 听 · 清 · 轻 · 醒

## ⑥ 写主歌 → 预副歌 → 桥段 → 尾奏

**主歌是"怎么走到副歌那句话"的过程。** 先问：从什么状态出发，才能让"空车厢 空站台"成立？
答：从**刚进站**开始——所以 V1 是一条动作链：进站 → 过闸机 → 玻璃反光 → 手机没电，不是四个并列镜头。

V2 要**推进一层**：换观察对象（从"我"看到"你留下的那首歌"），不是把 V1 换个说法。

```
[Intro]

[Verse 1]
末班车的风穿过衣领
闸机的红点亮了又停
玻璃里那张脸太安静
屏幕暗下去 剩信号灯 和百分之四的提醒

[Pre-Chorus]
再等三分钟
再撑三分钟
出口的风会比这里轻

[Chorus]
空车厢 空站台 空的回声
一个人的脚步声很重
整座城睡了 只有灯还醒
总有一班车 会开往晴空
往前走 出口越来越近
近到能听见 地面的风声

[Verse 2]
便利店的白灯太清醒
凉掉的咖啡握在手中
你嫌吵的那首歌 我循环到不停
我数着出口 数到地下几层

[Pre-Chorus]
再等三分钟
再撑三分钟
出口的风会比这里轻

[Chorus]

往前走 出口越来越近
近到能听见 地面的风声

[Breakdown]
其实也没有那么难撑
只是忽然想有人等
想有人问我一句 今天疼不疼

[Chorus]
```

主歌 / 预副歌 / 副歌是 4 / 3 / 6，互有差异。

## ⑦ 删

逐句问：**删掉它，歌更差吗？**

- `[Pre-Chorus]` 的"再撑三分钟"重复了第一句 —— 但这是刻意的推，不是废句，**留**
- "凉掉的咖啡握在手中"试删"握在手中"，只剩"凉掉的咖啡"——动作没了，冷也淡了，**留**
- 结尾"和一点点 还在跳动的灯"如果换成"和一点希望"，全首就塌了 ——
  **这句是全首唯一允许抽象的地方**，留

最后从头扫一遍：**有哪一句你会想跳过？** 没有——停在"还在跳动的灯"，没有把话说满。

**核对条件（`AGENTS.md` 第 4 节第 1–5 条）：全过。**

> 下面三条是**教学讲解**，真实交付不写（交付只有歌词 + 5 行话）：
> ① **细节成链** —— V1 是"进站 → 闸机 → 找座位 → 空车厢"一条动作线，不是四个并列镜头；
> ② **无抽象情绪词**，当代物件有手机电量"百分之四"、便利店、末班车；
> ③ **私人口吻**落在"你嫌吵的那首歌"与"我会假装说 还行"——改词时优先保护这两句。

### 对照：平均化写法长什么样

同一主题，按"安全模板"写会变成：

```
深夜我独自在地铁站
孤独像潮水般涌来
回忆在心头蔓延开
找不到你的存在
```

| 平均化 | 本例 |
| --- | --- |
| 深夜 | 凌晨一点、末班车 |
| 孤独 | 屏幕剩百分之四的提醒 |
| 回忆蔓延 | 你嫌吵的那首歌，我循环到不停 |
| 找不到你的存在 | 我会假装说 还行 |

**差的不是文采，是一个具体细节。**

## ⑧ 出提示词

> 同一步出两份：Suno 英文标签串、秒响中文长句。两者不互译，各写各的。

### Suno

**Style of Music（直接粘贴）**

```
dream pop, empty subway station at 2am, female alto, breathy, near-spoken, close-mic, felt piano, muted bass, brush snare, chamber strings, 70s tape saturation, 85 BPM, sparse intro, dynamic contrast
```

（14 个标签 / 199 字符，单行，可直接粘贴 —— 都贴着上限，说明取舍是必要的）

**Exclude Styles（直接粘贴）**

```
no autotune, no vocoder, no choir, no saxophone, no four-on-the-floor
```

> 一行中文：主风格选 dream pop 是因为它自带"空旷 + 混响"，不用另加空间效果；
> 人声三件套落在 `female alto`（音区）+ `breathy`（音色）+ `near-spoken`（唱法）；
> 质感靠 `close-mic` + `70s tape saturation`。

**（以下是讲解，不是交付内容 —— 逐标签解释属于「展开」，用户问了再给）**

| 标签 | 作用 |
| --- | --- |
| `dream pop` | 唯一主风格，定混响与音色基调 |
| `empty subway station at 2am` | **场景化情绪词**，替代裸情绪词 `melancholic` |
| `female alto` | 女声中低音区 —— 比 `female vocals` 多一个音区决定 |
| `breathy` | 气声（**音色**），贴合疲惫感 |
| `near-spoken` | 近独白（**唱法**）—— 三件套的第三件；主歌像说话，副歌才展开 |
| `close-mic` | 近讲（**空间**质感），耳边私密感 |
| `felt piano` | 呢垫钢琴，闷而软，不是通用 `piano` |
| `muted bass` | 闷音贝斯，冷且克制（字符预算下省略"立式"，秒响版仍写全） |
| `brush snare` | 刷鼓，避免军鼓的"打点感" |
| `chamber strings` | 室内乐四重奏编制 —— 比 `strings` 亲密得多，不会变罐头弦乐 |
| `70s tape saturation` | **年代 + 质感**，一个标签给两个维度 |
| `85 BPM` | 慢速，贴合疲惫感 |
| `sparse intro` | 动态词：引子极简 |
| `dynamic contrast` | 动态词：动态对比（配合歌词里的 `[Breakdown]`） |

**编曲事件的落点**：Suno 的 Style 字段写不下长句，事件分两处承载——

| 载体 | 内容 |
| --- | --- |
| Style 字段 | 只放动态词：`sparse intro`、`dynamic contrast` |
| **歌词结构标签** | 真正的事件落点：`[Breakdown]`（桥段抽掉节奏组，断崖） |

⚠️ `[Intro]` `[Outro]` `[Verse]` `[Chorus]` 是**普通结构标记**，任何歌都有，**不算事件**。
本例歌词里桥段用 `[Breakdown]` 而不是 `[Bridge]`，就是把"抽掉节奏组"这条事件落到了标签上。

**字符预算的真实取舍**：`sub bass drone`（地铁在地下的低频嗡鸣）最贴题，但加上会超 200 字符。
取舍结果：**反差元素放到秒响版承载**，Suno 版不硬塞；`70s tape saturation` 是质感（条件 10 要求），不是锚点。
这比硬塞进 200 字符更稳。

### 秒响

**直接粘贴**

```
现代都市抒情流行，略带 dream pop 质感，成年女声中低音区，副歌可上行至真声高音；
气声起句，咬字轻，句尾收音干净不拖泥带水；主歌接近独白，副歌转为舒展的实声。
呢垫电钢琴铺底，闷音立式贝斯，brush 军鼓，弦乐为室内乐四重奏编制、从第二段副歌才进入。
旋律以级进为主，副歌首句跳进后逐级回落，句尾不做装饰音。约 85 BPM。
前 12 秒只有电钢琴与低频持续音（地铁在地下的嗡鸣），人声第 12 秒进入；
主歌鼓组半速进入；桥段抽掉全部节奏乐器，留 4 秒纯人声干声、只留低频持续音垫底，
再全员进入最后一次副歌；尾奏逐层退去，最后一句气声收尾。
录音质感：单支铝带麦克风同期录制，70 年代磁带饱和，房间混响很短，保留一点录音室的空气声。
整体由清冷转向微暖。完整旋律演唱，不要 auto-tune，不要电音人声，不要合唱，不要萨克斯。
```

> One-line English: An urban pop ballad whose arrangement strips rather than builds —
> drums enter half-time, everything drops for four dry seconds in the bridge, and the last
> chorus is the only one at full weight.

**为什么秒响版比 Suno 版具体这么多**：秒响接受中文长句，**时间轴指令可以直接写**。
"第 12 秒入声""桥段抽掉节奏组留 4 秒"这类事件在 Suno 里只能靠结构标签暗示，在秒响里能明说。
这是秒响相对 Suno 最大的优势区。

## 真实交付长什么样

上面这一整篇是**教学用的展开版**。真实交付只有：

```markdown
# 歌词 ·《空车厢》v1

## 歌词
（上面那个代码块）

---
我用了 T1 抒情 ballad，85 BPM，副歌 6 句（这首要堆情绪，4 句不够）。
桥段用了 [Breakdown] 而不是 [Bridge]——那条停顿是全曲唯一的断点。
偷一句你自己的话当落点："我会假装说 还行"，改词时请别动这句。
```
