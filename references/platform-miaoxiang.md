# 秒响（Sway）提示词规范

> 供 `skills/song-prompt-builder/SKILL.md` 第 3 步使用。
> ⚠️ 秒响与 Suno **不是翻译关系**。Suno 要英文标签串，秒响要中文长句描述。
>
> **基准版本：v5.5。** 本规范按这个版本写。换版本前先确认三件事：
> 是否仍接受整段中文长句、是否支持段落 / 时间轴指令、九个要素里有没有哪项失效。

---

## 一、形态与预算

秒响接受**自然语言长句**，像给真人歌手 + 编曲写 brief。它的优势区间在**人声细节**与**演唱处理**——这些是 Suno 标签串表达不了的。

| | Suno | 秒响 |
| --- | --- | --- |
| 写法 | 英文标签串，逗号分隔 | **中文长句**，像给真人写 brief |
| 上限 | ≤ 1000 字符 | **≤ 1000 字符，含换行与标点**（v5.5 实测口径，2026-11 确认） |
| 优化目标 | 标签密度 + 互斥性 | **人声细节 + 演唱处理 + 段落指令** |

**上限怎么折算**：一个汉字 = 1 字符，一个标点 = 1 字符，一个换行 = 1 字符。
1000 字符 ≈ **800–880 个汉字（含标点）**。

⚠️ **1000 是天花板，不是目标。** 400 字能把该说的说完，就停在 400——
再往后写就是注水。预算的作用只有一条：**不用因为怕超而留泛词**
（`古风` `深情` `女声` 这类词不是因为写不下才留下的，是因为没想清楚）。

---

## 二、排版：按主题分段，不按要素分条

| 规则 | 说明 |
| --- | --- |
| **一句一件事**，句号断 | 长句内部用分号连同一类并列（配器、咬字），不要一逗到底 |
| **按主题换行** | 唱的人 / 咬字 / 怎么编 / 怎么走 / 质感——**按主题分，不按要素分**。换行也吃字符，别每项一行 |
| **不写编号、不写小标题、不用 markdown** | 平台按散文读；编号会让它把每项当独立指令 |
| **顺序 = 谁的份量最重** | 先说「谁在唱」，再说「什么在响」，最后说「怎么走」。人声放最前面 |

> 九要素是**查漏清单**，不是段落结构。按 1–9 逐项写成九句，读起来是表格，不是 brief。
> 一个要素可以在两句里说完，两个要素也可以合在一句里。

---

## 三、优先级：什么必写、什么先砍

### 必写（缺了这项，生成出来复现不出这首歌）

| 项 | 要写到什么程度 |
| --- | --- |
| **人声身份** | 性别 + 年龄感 + 音区 + 音色（`沙而不哑`，不是`好听的男声`） |
| **唱法** | 发声方式（本嗓 / 假声 / 胸声）+ 力度控制（压着唱 / 放开不喊） |
| **配器** | 3–5 件，**每件带演奏法或器材**（`板鼓只打板眼不填花`，不是 `鼓`） |
| **速度与律动** | 区间 + 怎么摆（`约 125–132 BPM，鼓走板不走拍`） |

### 该写（决定它是"这一首"还是"这类歌"）

| 项 | 为什么 |
| --- | --- |
| **段落与时间轴** | 第几秒入声、哪里抽空、哪里加层、怎么收——**这是秒响相对 Suno 最大的优势**（Suno 的 Style 没有段落概念） |
| **录音质感** | 话筒 / 介质 / 空间。写"温暖"没用，写"单支铝带话筒同期，磁带饱和" |
| **风格的具体化** | 不是 `古风`，是 `京腔化新古风`；不是 `电子`，是 `Future bass` + 具体做法 |
| **负面** | "不要 XX"（**参考，不是条件**）。这个平台没有排除字段，只能写在文字里；写它会占字符，位置紧张时让路 |

### 可省（写不下或写多了会水）

| 项 | 处理 |
| --- | --- |
| 情绪形容词（`深情地` `有力量`） | 删——没有指向，写了等于没写 |
| 点缀乐器（环境采样、scratch） | 只在前四项都写透了再加 |
| 旋律走向的细节 | 只写**关键那句**（副歌首句怎么跳、末句怎么收） |
| 完整度声明（`完整旋律演唱`） | 末尾一句带过即可，不必展开 |

### 预算有余时，按这个顺序加

1. **人声形容词具体化**——`气声` → `气声为主，句尾漏气，不修齿音`
2. **段落事件**——`第二段副歌后抽掉全部鼓与笙，留 4 秒只有人声`
3. **每件乐器的演奏法**——`钢琴` → `闷音钢琴，只弹中音区，不踩踏板`
4. **录音方式**——话筒型号、介质、房间
5. **关键句的唱法**——`最后一句降半音唱`

### 近上限时，按这个顺序砍

情绪形容词 → 点缀乐器 → 旋律走向细节 → 完整度声明 → 风格修饰词

⚠️ **人声、配器演奏法、段落时间轴、速度——这四项不砍。** 宁可把别处删干净。
> 负面不在其中：它有用，但和"复现这首歌"无关，字符紧张时它是第一个让路的。

## 四、九要素（查漏用，不是填写顺序）

| # | 要素 | 写什么 | 例 |
| --- | --- | --- | --- |
| 1 | **风格 / 唱腔** | 曲风 + 唱腔特征 | 京腔化新古风 |
| 2 | **人声性别与音区** | 性别、年龄感、音区 | 北方成年男中低音 |
| 3 | **发声方法** | 本嗓/假声、胸声/头声、共鸣位置 | 京剧老生本嗓大嗓，全程胸声实音 |
| 4 | **咬字与字词处理** | 字头、喷口、收音、字与拍的关系 | 字头硬，喷口短，一字一拍 |
| 5 | **板式 / 节奏 / BPM** | 节拍型、速度**区间** | 西皮原板板眼，约 125–132 BPM |
| 6 | **配器** | 3–5 件核心乐器及其演奏法 | 板鼓点板，京胡两音短答，低音笙只吹根音 |
| 7 | **旋律走向** | 音区范围、句尾处理、装饰 | 旋律始终在中低音区，句尾同音短反复后下行收住 |
| 8 | **入声时机与段落** | 何时进人声、段落安排 | 第二秒入声，第二段副歌后留 8 秒纯器乐 |
| 9 | **录音质感 + 完整度** | 空间感、是否完整演唱 | 录音室近声，完整旋律演唱 |

**写完扫一遍这张表，缺哪项心里有数就行**——不必逐项补齐，更不必写"缺项说明"。

## 五、模板

### 通用骨架

> ⚠️ 下面是**骨架**（约 170 字符，**只用了一成七预算**）。按第三节的优先级往里加，
> 加到 300–500 字符通常是合适的落点。

```
{风格/唱腔}，{性别年龄}人声，{音区}，{音色一句话}。{发声方法}，{力度控制}；{咬字处理}，{句尾处理}。
{板式节奏}，约 {BPM 区间}，{律动}；{配器1}+{演奏法}，{配器2}+{演奏法}，{配器3}+{演奏法}。
第{N}秒入声，{段落事件}，{收尾方式}。
{录音方式}，{介质/空间}。不要{X}，不要{Y}。
```

### 分风格骨架（按上表加密度，别照抄长度）

> ⚠️ 每条末尾的 `{X}` 是**负面**，**可选**：这个风格有明确要排除的就填，没有就整句删掉。
> 别为了"占位"硬写一条——那是假满足。五个骨架只示范结构，不示范词，照抄配器组合就又成了罐头。

**古风 / 戏曲**
```
京腔化新古风，北方成年男中低音，京剧老生本嗓大嗓，全程胸声实音。
字头硬，喷口短，一字一拍，西皮原板板眼；板鼓点板，京胡两音短答，低音笙持续长音只吹根音。
旋律始终在中低音区，句尾同音短反复后下行收住。约 125–132 BPM，第二秒入声，
录音室近声，完整旋律演唱。不要 {X}。
```

**流行抒情**
```
现代流行抒情，成年女声，中低音区为主，副歌可上行至真声高音。
气声起句，咬字轻，句尾收音干净不拖。钢琴铺底，闷音贝斯，brush 军鼓，
副歌加入弦乐 pad。旋律以级进为主，副歌首句跳进后回落。
约 82–88 BPM，前 15 秒纯钢琴引子，第二段副歌后留 8 秒纯器乐桥段。
录音室近声，带轻微空间混响，完整旋律演唱。不要 {X}。
```

**电子舞曲**
```
Future bass，成年女声，中高音区，亮而有颗粒感。
主歌气声近讲，副歌转实声全力，副歌加双层和声。
808 鼓组，低音 bass 厚重，arp 合成器，drop 段加 saw lead。
四四拍，每拍一记底鼓，约 124–130 BPM。前 8 秒 build-up，
drop 前留一拍空白。现代电子母带质感，低频饱满，完整旋律演唱。不要 {X}。
```

**说唱**
```
Boom bap 说唱，成年男声，中低音区，颗粒感强。
咬字清晰，字头重，句中韵密集，句尾收音短促。
采样钢琴 loop，粗粝鼓组，upright bass，scratch 点缀。
约 88–95 BPM，laid-back 律动，人声略滞后于拍。第 4 秒入声。
老式磁带质感，带底噪，完整段落演唱。不要 {X}。
```

**纯音乐**
```
电影感氛围电子，全程纯器乐，无人声。
模拟合成器 pad 缓慢演进，颗粒化织体，加入雨声环境采样，无打击乐。
约 55–65 BPM 的感觉，无明确节拍。空间混响开阔，层次由薄至厚再回落。
不要人声，不要明显鼓点，不要旋律性主奏。
```

### 一条写满的示范

同一个古风题材，从骨架的 135 字符写到 **402 字符**（约四成预算）。
多出来的 267 字符买到了什么，逐条标在旁边：

```
京腔化新古风，北方成年男中低音，四十岁上下的嗓子，沙而不哑。京剧老生本嗓大嗓，全程胸声实音，不用假声；主歌压着唱，副歌放开但不喊，最高只到换声区前一格。
字头硬，喷口短，一字一拍，休止比字多；上声字往下压，句尾一律收干净、不留气声拖尾，拖腔只放在每段末句的最后两字。
板式取西皮原板板眼，约 125–132 BPM，鼓走板不走拍，第二段起加一记闷锣。配器五件：板鼓只打板眼不填花，京胡两音短答只接上句尾，低音笙长音只吹根音，月琴扫反拍，桥段进一台失真合成器低频压住整段，是全曲唯一的重东西。
旋律集中在中低音区，级进为主，副歌首句四度跳进后逐级回落。第 2 秒入声，无前奏；第二段副歌后抽掉全部鼓与笙，留 4 秒只有人声和京胡；末段副歌叠一层假声和声，不占主旋律；最后一句唱完直接收，不拖尾奏。
单支铝带麦克风近声同期录制，70 年代磁带饱和，房间声收进去，不修齿音。不要戏腔假声，不要大混响，不要电鼓。
```

| 多出来的部分 | 买到什么 |
| --- | --- |
| `四十岁上下的嗓子，沙而不哑` | 把人声从"男中低音"缩到一个能想起来的声音 |
| `主歌压着唱，副歌放开但不喊，最高只到换声区前一格` | 力度曲线——决定副歌会不会唱成喊 |
| `上声字往下压`、`拖腔只放在末句最后两字` | 唱腔处理，本地化细节，Suno 标签写不出来 |
| `第二段起加一记闷锣`、`桥段进失真合成器` | 段级事件 + 反差锚点（古的混进一台重音色） |
| `第 2 秒入声，无前奏`、`抽掉鼓与笙留 4 秒`、`末段叠假声和声` | 时间轴——秒响唯一能做、Suno 做不到的事 |
| `单支铝带麦克风同期，磁带饱和，不修齿音` | 质感从形容词变成工序 |

> ⚠️ **这是密度示范，不是配方。** 照抄它的配器和"失真合成器"这个反差，就变成新的罐头了——
> 学的是**每一格写到多细**，不是这一格写了什么。

## 六、常见错误

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 把 Suno 英文标签直译丢进去 | 描述过碎，生成不稳 | 按九要素重写长句 |
| 只写"好听的古风歌" | 完全随机 | 至少写满"必写"那四项 |
| **只交骨架**（150 字上下） | 生成的是一类歌，不是这一首 | 按第三节的加长顺序补到 300–500 字符 |
| **为了写满而堆形容词** | 水，且互相抵消 | 1000 是上限不是目标；写透了就停 |
| 人声只写"女声" | 音色随机 | 补音区、发声方法、咬字 |
| 不写入声时机 | 前奏长度不可控 | 写"第 N 秒入声" |
| 段落只写"副歌更炸" | 编曲不知道炸在哪 | 写成事件：抽掉什么、加什么、留几秒 |
| 有明确要排除的，却没写 | 那个元素真会出现 | 写"不要 XX"（**参考项**：看得出来这个风格最可能怎么失败时才写） |
| 分点列条写 | 平台解析不如长句稳 | 按主题分段，一段内用标点连 |
| **超了 1000 字符** | 会被截断，尾部的指令直接丢失 | 先砍情绪形容词和点缀乐器，别砍时间轴 |

## 七、交付前数一样

**字符数 ≤ 1000**（含换行与标点，条件 6）——换行也算，别按"字数"估。

其余是参考：负面、九要素、时间轴，写顺了不用逐项对。
