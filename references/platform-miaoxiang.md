# 秒响（Sway）提示词规范

> 供 `skills/song-prompt-builder/SKILL.md` 第 3 步使用。
> ⚠️ 秒响与 Suno **不是翻译关系**。Suno 要英文标签串，秒响要中文长句描述。

---

## 一、形态认知

秒响接受**自然语言长句**，像给真人歌手 + 编曲写 brief。它的优势区间在**人声细节**与**演唱处理**——这些是 Suno 标签串表达不了的。

**对比**：

| | Suno | 秒响 |
| --- | --- | --- |
| 写法 | `guofeng, chinese style, male vocals, opera style, guzheng, erhu, 129 BPM` | "京腔化新古风，北方成年男中低音，京剧老生本嗓大嗓，全程胸声实音。字头硬，喷口短，一字一拍，西皮原板板眼；板鼓点板，京胡两音短答。旋律始终在中低音区，句尾同音短反复后下行收住。约 129 BPM，第二秒入声，录音室近声，完整旋律演唱。" |

秒响版本**长得多，也具体得多**。这就是差异所在。

## 二、九要素清单

按此顺序组织，用逗号 / 分号 / 句号连成一整段（**不要分点列条**）：

| # | 要素 | 写什么 | 例 |
| --- | --- | --- | --- |
| 1 | **风格 / 唱腔** | 曲风 + 唱腔特征 | 京腔化新古风 |
| 2 | **人声性别与音区** | 性别、年龄感、音区 | 北方成年男中低音 |
| 3 | **发声方法** | 本嗓/假声、胸声/头声、共鸣位置 | 京剧老生本嗓大嗓，全程胸声实音 |
| 4 | **咬字与字词处理** | 字头、喷口、收音、字与拍的关系 | 字头硬，喷口短，一字一拍 |
| 5 | **板式 / 节奏 / BPM** | 节拍型、速度 | 西皮原板板眼，约 129 BPM |
| 6 | **配器** | 3–5 件核心乐器及其演奏法 | 板鼓点板，京胡两音短答 |
| 7 | **旋律走向** | 音区范围、句尾处理、装饰 | 旋律始终在中低音区，句尾同音短反复后下行收住 |
| 8 | **入声时机与段落** | 何时进人声、段落安排 | 第二秒入声，第二段副歌后留 8 秒纯器乐 |
| 9 | **录音质感 + 完整度** | 空间感、是否完整演唱 | 录音室近声，完整旋律演唱 |

---

## 三、写作要点

1. **一整段**，用标点分隔，不要写成清单或表格
2. **人声写得越细越好**——这是秒响相对 Suno 的核心优势，别浪费
3. **可以给微观指令**：旋律走向、句尾处理、某一句怎么唱、第几秒入声
4. **不想要的直接写**："不要电音，不要 auto-tune，不要合唱"
5. **BPM 用中文数字或直接数字**均可："约 129 BPM" / "约一百二十九 BPM"
6. 纯音乐就写"全程纯器乐，无人声"

## 四、模板

### 通用模板

```
{风格/唱腔}，{性别年龄}人声，{音区}。{发声方法}，{咬字处理}，{字拍关系}。
{板式节奏}，约 {BPM} BPM；{配器1}，{配器2}，{配器3}。
旋律{走向描述}，句尾{处理}。第{N}秒入声，{段落安排}。
{录音质感}，{完整度}。
```

### 分风格模板

**古风 / 戏曲**
```
京腔化新古风，北方成年男中低音，京剧老生本嗓大嗓，全程胸声实音。
字头硬，喷口短，一字一拍，西皮原板板眼；板鼓点板，京胡两音短答。
旋律始终在中低音区，句尾同音短反复后下行收住。约 129 BPM，第二秒入声，
录音室近声，完整旋律演唱。
```

**流行抒情**
```
现代流行抒情，成年女声，中低音区为主，副歌可上行至真声高音。
气声起句，咬字轻，句尾收音干净不拖。钢琴铺底，闷音贝斯，brush 军鼓，
副歌加入弦乐 pad。旋律以级进为主，副歌首句跳进后回落。
约 85 BPM，前 15 秒纯钢琴引子，第二段副歌后留 8 秒纯器乐桥段。
录音室近声，带轻微空间混响，完整旋律演唱。
```

**电子舞曲**
```
Future bass，成年女声，中高音区，亮而有颗粒感。
主歌气声近讲，副歌转实声全力，副歌加双层和声。
808 鼓组，低音 bass 厚重，arp 合成器，drop 段加 saw lead。
四四拍，每拍一记底鼓，约 128 BPM。前 8 秒 build-up，
drop 前留一拍空白。现代电子母带质感，低频饱满，完整旋律演唱。
```

**说唱**
```
Boom bap 说唱，成年男声，中低音区，颗粒感强。
咬字清晰，字头重，句中韵密集，句尾收音短促。
采样钢琴 loop，粗粝鼓组，upright bass，scratch 点缀。
约 92 BPM，laid-back 律动，人声略滞后于拍。第 4 秒入声。
老式磁带质感，带底噪，完整段落演唱。
```

**纯音乐**
```
电影感氛围电子，全程纯器乐，无人声。
模拟合成器 pad 缓慢演进，颗粒化织体，加入雨声环境采样，无打击乐。
约 60 BPM 的感觉，无明确节拍。空间混响开阔，层次由薄至厚再回落。
不要人声，不要明显鼓点，不要旋律性主奏。
```

## 五、常见错误

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 把 Suno 英文标签直译丢进去 | 描述过碎，生成不稳 | 按九要素重写长句 |
| 只写"好听的古风歌" | 完全随机 | 至少覆盖九要素中的 7 项（缺项必须说明原因） |
| 人声只写"女声" | 音色随机 | 补音区、发声方法、咬字 |
| 不写入声时机 | 前奏长度不可控 | 写"第 N 秒入声" |
| 不给负面描述 | 出现不想要的元素 | 直接写"不要 XX" |
| 分点列条写 | 平台解析不如长句稳 | 连成一整段 |
