# 歌词创作的基本盘

> 这份文件不是本项目的经验，是**外部实践**：华语一线词人的公开说法 + 英语流行歌曲写作的通行做法 + 判断。
> 判断项目做法对不对，以这里为准。**项目规则与这里冲突时，先怀疑项目。**
>
> 来源：`[方]` 方文山（北艺大 IMPACT 讲座）、`[行]` 欧美 songwriting 通行做法、`[判]` 本文档的判断。

---

## 零、一句话

> **歌词是一个人在某个处境里，对某个人说的一段话，被谱成了曲。**

不是诗（不靠意象密度取胜），不是散文（不负责把事讲清楚），不是文案（不负责传达信息）。

这句话决定了后面所有事：
- 有"一个人" → 要有处境，不能是泛指的情绪
- 有"对某个人" → 要有听话的人，哪怕他不在场
- 是"一段话" → 有说出口和没说出口的区别
- "被谱成曲" → 受字数和呼吸限制

## 一、从哪开始

### 1. 从副歌写起，不从第一行

> `[方]`「填词可以当作是一种电影剪辑的艺术，**从副歌先写起**，因为那最具原创性与记忆点，**千万不要很制式的从第一行开始**。」
> `[行]` "Start with the hook, not the first line."

副歌是唯一会被反复听的部分。主歌的存在是为了把它送到听众面前。
先写主歌 = 不知道要送到哪就开始修路。

### 2. 从一个具体的时刻起，不从主题起

❌ 主题：写一首关于「异地恋」的歌
✅ 时刻：视频通话卡住的那三秒，她在那头笑，画面停在半张脸上

主题会导向"关于它的正确说法"，时刻会导向"那天到底发生了什么"。
`[方]`「创作首需学会观察。」

### 3. 先定"谁在说话"

四件事，缺一件语气就不对：

| 问 | 答得含糊会怎样 |
| --- | --- |
| 这个人是谁（处境，不是身份） | 变成"作者在描述一段感情" |
| 他在对谁说（在场 / 不在场） | 在场会写成对白，不在场才写得成独白 |
| 什么时候说的（事后多久） | 决定时态，也决定克制的程度 |
| **说完想干什么** | 想说服对方 / 想说服自己 / 什么都不图只是说出来——三种说法完全不同 |

第四问最关键。没有它，写出来的永远是"正确但没人"的句子。

## 二、词：用什么语言

### 1. 名词和动词承担一切，形容词越少越好

形容词是**作者在评价**，名词和动词是**事物本身**。

| 评价 | 事物 |
| --- | --- |
| 孤独的街道 | 便利店的白灯亮着，只有一个人在换零钱 |
| 她很温柔 | 她把伞往我这边偏了一点 |
| 心碎 | 我没删 |

`[判]` 这条比"抽象词换具象"更根本：**不是把"孤独"换成"空椅子"，是删掉所有评价，只留事物。**

### 2. 口语，但不等于完整句

> `[行]` "If a line could appear on a greeting card, rewrite it immediately."

判断标准不是"像不像日常对话"（日常对话是"我买了、你吃了吗"，写进歌里照样是散文），
而是"**这个人会不会这么说**"——他可能只说半句，可能词不达意，可能说反话。

### 3. 不解释

五种句子会把歌词变成散文，共同点是**把话说完了**：

| 类型 | 例 | 病在哪 |
| --- | --- | --- |
| 交代 | 结果真下了 你把我拽到屋檐 | 有时间顺序和因果 |
| 解释 | 我想念你 因为你已经离开 | "因为"一出现就是说明文 |
| 描述 | 深夜的城市很孤独 | 形容词 + 抽象名词 |
| 总结 | 我早该放手 | 替听众下了结论 |
| 对白 | 我说我没事 你只说 吃完 | 把对话原样记下来 |

## 三、句：一句是什么

### 1. 一句一个画面或一个动作

不是"一件完整的事"，是"一个镜头"。

> `[方]`「上一句**不一定要接着下一句**，透过时间场景的转移来让歌词呈现临场感。」

所以句子之间可以是：因果、递进、转折，**也可以是并置**。
判据不是"接不接得上"，是"有没有一条线"（视线、时间、同一个物件、同一个念头）。
并置有共同的东西，流水账没有。

### 2. 说完还有余

好的句子结束时，有东西悬着：

| 句子 | 悬着什么 |
| --- | --- |
| 故事的小黄花 从出生那年就飘着 | 飘到哪 |
| 很久没有你的消息 我也没有打听 | 为什么不打听 |
| 越过山丘 虽然已白了头 | 越过之后呢 |

说完就什么都不剩的句子（`结果真下了 你把我拽到屋檐`），是交代。

### 3. 句内有张力

两个不匹配的东西碰在一起：
越过 × 白了头（达成 × 代价）、可惜不是你 × 陪我到最后（遗憾 × 期待）。

没有张力的句子是单向陈述，信息清楚，但只有一个方向。

### 4. 可唱

`[判]` 这是歌词与诗的唯一硬区别，三条可查：

- **一口气说得完**（快歌更严，慢歌更宽）
- **没有需要停下来才说完的结构**——比较句（`比…早`）、长定语、条件句
- **中文特有**：句尾 / hook / 长音位的字，声调不能与旋律走向打架（倒字）

## 四、段：一段是什么

### 1. 一段一个落点

四句或六句不是平均用力，是**朝一个地方走**。
落点可以是画面（风扇把我转进梦）、动作（抬头看天）、或一个反差。

检查：**盖住前三句读末句，站得住吗？** 站不住，说明末句只是最后一句。

### 2. 段不解释上下文

`七点半的电视 播着明天` 不交代"那天我在哪"；
`那年的夏天 我们在操场` 就是在交代。

### 3. 段的长度由内容定，不由形式定

行数相等只在**同旋律重复段**之间才是硬要求（V1=V2、C1=C2），因为那是同一段曲子。

## 五、首：一首是什么

### 1. 主歌具体，副歌普世

> `[行]` "**Universality in the chorus, specificity in the verse.**"
> 主歌 `I drive all night`（具体）→ 副歌 `I can't fight this feeling anymore`（普世）。

| 段落 | 干什么 | 不能干什么 |
| --- | --- | --- |
| Verse | 讲一件**具体的事**：一个场景、一个动作、一个时间点 | 不解释情绪 |
| Pre-Chorus | 积累张力 | 不展开新信息 |
| Chorus | 把具体的事变成**所有人共有的那种感受** | 不讲新情节 |
| Bridge | 换视角 / 说出前面没说的那句 | 不重复副歌 |
| Outro | 停住 | 不总结 |

**主歌如果自己在说"我很难过"，副歌就没有可升的东西。**

### 2. hook 能脱离上下文

一首歌的记忆点，必须短、能重复、**单独拿出来还成立**。
`[行]` 标题通常出现在副歌，而且常在首句或末句。

### 3. 情绪有起落，不是一路堆

一路往上堆 = 没有对比 = 没有高潮。
要有低处（抽空、留白、只有人声），高处才有意义。

### 4. 结尾停住

好歌词的结尾多数是**画面定住**或**话没说完**，不是把道理讲完。

## 六、华语特有

| 事项 | 要点 |
| --- | --- |
| **声调与旋律**（倒字） | 句尾 / hook / 长音位优先平声，避免上声；去声配下行会加倍下滑。写词时无旋律，先按位置默认 |
| **十三辙** | 开口度配情绪（激昂用江阳/言前/发花，低回用一七/姑苏/由求）；副歌定一辙 |
| **押韵** | 辅助记忆，**非必需**（`[行]` "rhyme is not required"）。副歌押住，主歌可松；为押韵改坏好句子是净损失 |
| **文白** | 口语是默认，文言是风格选择。混用会出戏，除非整首统一 |
| **人称代词** | `[方]`「人称代词一定要留着，画面才会越显鲜明，仿佛置身其中。」承担视角的留，只当动作主语的删 |

## 七、怎么判断好不好

### 四个外部测试（行业里实际在用的）

1. **哼回测试**：只听一遍，20 分钟后还能哼出副歌吗
2. **只看副歌**：只读副歌，知道这首歌在说什么吗
3. **陌生人反应**：看他在副歌时的表情，不是听他说什么
4. **一句能当歌名**：有没有一句话，短到能当标题、又撑得起整首

### 一个自查

逐句问：**这句话，换一个人说，还成立吗？**
成立 → 它还是平均化的。不成立 → 它属于这个人。

## 八、优先级（冲突时谁赢）

`[判]` 把上面所有条目按"坏了就毁歌"排序：

1. **有一个人在说话**（没有它，其余全是空的）
2. **可唱**（唱不了就不是歌词）
3. **不解释**（一说尽就成散文）
4. **主歌具体 / 副歌普世**（分工错了，整首散架）
5. **句子有余味**（决定它是歌词还是顺口溜）
6. 押韵、句长对齐、句式工整（都可以让）
