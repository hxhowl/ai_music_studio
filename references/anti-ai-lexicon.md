# 去 AI 味 · 取材词库

> **这是一份"该去找什么东西"的词库，不是句子模板。**
> 右栏给的是**取材方向**（什么物件、什么动作），不是"照着这句写"。
> 句子怎么造，归 `skills/lyric-zh/SKILL.md` 第五节管——本文件不答那个问题。
>
> 立场：**不是禁用某些词，是禁止它们在没有具体支撑的情况下单独出现。**
>
> ⚠️ **本文件里举的例子会变成新的陈词。** 同一个示例在项目里复述三次，
> 模型就把它当标准答案背下来——`把伞吹翻的雨`、`牙刷还在杯子里` 已经发生过一次。
> 所以：**看方向，不要抄句子。**

---

## 写在最前面：两个判断动作

词库只是检索入口。真正管用的是这两个动作，它们对任何句子都成立：

1. **能被镜头拍到吗？** 拍不到"孤独"，拍得到"手机扣在桌上，屏幕朝下"。
2. **换到另一首歌里还成立吗？** 成立 = 它没有被这首歌限定 = 它是通用件。

⚠️ **不要数"用了几个抽象词"。** 写成数字就会被当成指标——删够三个，剩下的照样平均化。

## A. 抽象情绪词：不是禁词，是"不能单独撑一句"

孤独 寂寞 忧伤 彷徨 迷茫 悲伤 痛苦 失落 绝望 思念 眷恋 牵挂 心碎 泪水
灵魂 永恒 永远 命运 人生 时光 岁月 流年 回忆 梦境 远方 归途 初心 遗憾 温柔（作名词）

**判据**：这个词能不能被镜头拍到？拍不到，就说明这句只有它在撑着。

⚠️ 它出现在歌里是完全可以的——`我有点孤独` 这种直说，在**特定的人、特定的处境**下是成立的
（一个不会表达的人、一句自嘲、一次终于承认）。错的是**整首都在用它，而没有任何一件具体的东西**。

---

## B. 通用意象：限定要来自那个场景

| 裸词 | 限定从哪来（示例，别照抄） |
| --- | --- |
| 风 | 把便利店招牌吹得晃了一下 —— 限定来自**在场的东西** |
| 星 | 城市里其实看不见几颗 —— 限定来自**这个地点的事实** |
| 月 | 凌晨四点还挂在天上 —— 限定来自**时间** |
| 深夜 | 便利店换班的那个点 —— 限定来自**这个时段特有的动作** |

**规则只有一条**：限定必须来自 ⓪ 那个场景里**真实存在**的东西（时间 / 地点 / 在场物件 / 正在发生的事），
**不是给它加一个形容词**。"温柔的月光"不是限定，"他阳台那盆花上的月"是。

⚠️ **`把伞吹翻的雨` 不要再用。** 它在本项目里已经是标准答案，是新的陈词。
写雨就写这场雨在这首歌里**具体做了什么**：伞骨断了、鞋里灌满了、快递箱塌了。

## C. 陈词比喻：整句靠它撑着才算错

**不拉黑。** 一个比喻本身没有罪——错的是**那句话除了它没有别的内容**。

**判据（可查）**：去掉这个比喻，这句还剩什么？
- 还剩一件具体的东西 → 可以用
- 什么都不剩 → 它在替你抒情，删

**三种可以用的情形**：

1. **人物语言** —— 说话的人本来就没什么词，或者他就是在说套话
   （跟长辈打电话、念稿、面试、悼词）
2. **反讽** —— 明着用，下一句自己拆掉
   `心如刀割／刀还没拔出来 我已经在想 要不要发朋友圈`
3. **句中零件** —— 整句有具体的东西，比喻只是其中一个词，不是支点

⚠️ **用它的理由不能是"我想不出别的"。** 想不出别的，说明这句本来不该存在。

最常见的（**不是全集**）：像潮水般涌来 / 心如刀割 / 泪如雨下 / 时光荏苒 / 岁月如梭 /
如梦初醒 / 恍如隔世 / 一缕阳光 / 一丝希望 / 无尽的黑暗 / 化作尘埃 / 刻骨铭心 /
痛彻心扉 / 无法自拔 / 命中注定

英文同理：cuts me to the bone / tears me apart / can't heal this pain / empty inside /
broken heart / time heals all / set me free

> ⚠️ **名单治的是最出名的几个，不是这个病。** 把「心如刀割」换成「心脏像被人攥住」，
> 一样是陈词，只是没那么出名——**它逃得过名单，逃不过"去掉之后还剩什么"。**

## D. 取材方向（中文）

> 右栏是**去找什么**，不是"这么写"。写成一句什么话，是句子的事（`lyric-zh` 第五节）。
> ⚠️ 找不到对应的行是**正常的**——表是方向，不是清单。照着表逐行对，就会写出"一句一个物件"的分镜表。

| 想表达 | 别这么写 | 去找什么（物件 / 动作） |
| --- | --- | --- |
| 孤独 | 我好孤独 | 外卖备注写"放门口"；点单时习惯性只点一份 |
| 想念 | 我深深想念你 | 没删的旧聊天记录；没改的密码 |
| 难过 | 心如刀割 | 手机扣在桌上、屏幕朝下；饭剩了一半 |
| 疲惫 | 身心俱疲 | 坐过站；钥匙插在门上忘了拔 |
| 疏远 | 我们渐行渐远 | 停在三个月前的对话框；共同群聊设了免打扰 |
| 遗憾 | 无尽的遗憾 | 钱包夹层里的票根；没拆的快递 |
| 心动 | 怦然心动 | 记住对方随口说的口味；多买了一份 |
| 放不下 | 我始终放不下 | 没改的密码；相册里没删的照片 |
| 等一个人 | 我在等你回来 | 电梯一停就抬头；听见楼道脚步 |
| 时间流逝 | 时光荏苒 | "去年今日"那张还没删；会员到期前一天 |
| 假装没事 | 我强颜欢笑 | 朋友圈照发；但不回消息 |
| 关系结束 | 我们走到了尽头 | 还没还的钥匙；留在柜子里的东西 |

## F. 当代生活物件库（时代标记）

> 用一两个就够了，**不用凑数**——凑出来的物件和凑出来的名词是同一回事。
>
> ⚠️ **界面可以当素材，不能当句子的主角。** `屏幕暗下去` 可以（人在看着它暗）；
> `"对方正在输入"闪了一下` 不行（那是一行字在闪）。区别：前者是场景里的一个东西，
> 后者是一串字符串——**唱一句引号里的字，等于念标识牌**。

**通讯**：微信置顶 / 已读不回 / 撤回 / 免打扰 / 朋友圈三天可见 / 58 秒语音条 / 群聊设免打扰

**出行**：末班车 / 共享单车 / 打车排队第 7 位 / 高铁改签 / 航班延误 / 地铁坐过站 / 导航说"已偏航"

**消费**：外卖 / 快递柜取件码 / 购物车没结算 / 便利店关东煮 / 扫码支付失败 / 会员到期提醒

**设备**：电量 12% / 低电量模式 / AirPods 只剩一只 / 屏幕使用时间周报 / 耳机线绕两圈 / 充电宝没还

**居家**：洗衣机还在转 / 外卖盒没扔 / 冰箱贴 / 门禁卡 / 晾了三天的衣服 / 备用钥匙

## G. 一句判据

写完一段，问自己：

> **这段里有没有一个细节，是别人写不出来的？**

如果没有，这段就是平均化的——换任何一个模型都能写出来。去补那个细节。
