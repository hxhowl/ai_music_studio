# 词库：哪些词是空的、陈的、要限定的

> 这份文件管**词的性质**。它不管句子怎么写，也**不给"该换成什么"的对照表**。
>
> - 想不出画面 → `skills/lyric-imagery-rhyme/SKILL.md`（从场景边界出发，按感官展开）
> - 写完够不够凝练 → `skills/lyric-naturalness/SKILL.md`（删一遍，看损失什么）
>
> ⚠️ **不要在这里找"表达 X 该用什么词"。** 歌词不从"我要表达孤独"出发，
> 从"我在哪、看见什么"出发。先有情绪再找对应物，那是作文的象征手法——
> 写出来的是一段带例子的说明文，不是歌词。

---

## A. 空的词

孤独 寂寞 忧伤 彷徨 迷茫 悲伤 痛苦 失落 绝望 思念 眷恋 牵挂 心碎 泪水
灵魂 永恒 永远 命运 人生 时光 岁月 流年 回忆 梦境 远方 归途 初心 遗憾 温柔（作名词）

**判据**：这个词能不能被镜头拍到？拍不到，就说明这一句只有它在撑着。

⚠️ **它们不是禁词。** `我有点孤独` 在特定的人嘴里是成立的（一个不会表达的人、一句自嘲、
一次终于承认）。不成立的是：**整首都在用它们，而没有任何一件具体的东西。**

⚠️ **不要数"用了几个"。** 写成数字就会变成指标——删够三个，剩下的照样空。

---

## B. 要限定的词

风 / 雨 / 月 / 星 / 海 / 落叶 / 黄昏 / 深夜 / 阳光——这类词单放着哪儿都能用，等于哪儿都不属于。

**规则只有一条：限定必须来自那个场景里真实存在的东西**（时间 / 地点 / 在场物件 / 正在发生的事）。
**不是给它加形容词。**

```
"温柔的月光"         ✗ 加的是评价
"凌晨四点还挂在天上"    ✓ 限定来自时间
"城市里其实看不见几颗"  ✓ 限定来自这个地点的事实
```

**判据**：这个意象换到另一首歌里还成立吗？成立就是没限定。

## C. 陈的词

**不拉黑。** 一个比喻本身没有罪——错的是**那句话除了它没有别的内容**。

**判据（可查）**：去掉这个比喻，这句还剩什么？
- 还剩一件具体的东西 → 可以用
- 什么都不剩 → 它在替你抒情，删

**三种可以用的情形**：

1. **人物语言** —— 说话的人本来就没什么词，或者他就是在说套话
   （跟长辈打电话、念稿、面试、悼词）
2. **反讽** —— 明着用，下一句自己拆掉
   `心如刀割／刀还没拔出来 我已经在想 要不要发朋友圈`
3. **句中零件** —— 整句有具体的东西，比喻只是其中一个词，不是支点

⚠️ **用它的理由不能是"我想不出别的"。** 想不出别的，说明这句本来不该存在。

常见的（**不是全集**）：像潮水般涌来 / 心如刀割 / 泪如雨下 / 时光荏苒 / 岁月如梭 /
如梦初醒 / 恍如隔世 / 一缕阳光 / 一丝希望 / 无尽的黑暗 / 化作尘埃 / 刻骨铭心 /
痛彻心扉 / 无法自拔 / 命中注定

英文同理：cuts me to the bone / tears me apart / can't heal this pain / empty inside /
broken heart / time heals all / set me free

> ⚠️ **名单治的是最出名的几个，不是这个病。** 把「心如刀割」换成「心脏像被人攥住」，
> 一样是陈词，只是没那么出名——**它逃得过名单，逃不过"去掉之后还剩什么"。**

## D. 时代的词（物件库）

> 用一两个就够了，**不用凑数**——凑出来的物件和凑出来的名词是同一回事。
>
> ⚠️ **界面可以当素材，不能当句子的主角。** `屏幕暗下去` 可以（人在看着它暗）；
> `"对方正在输入"闪了一下` 不行（那是一行字在闪）。区别：前者是场景里的一个东西，
> 后者是一串字符串——**唱一句引号里的字，等于念标识牌**。

**通讯**：微信置顶 / 已读不回 / 撤回 / 免打扰 / 朋友圈三天可见 / 58 秒语音条 / 群聊设免打扰

**出行**：末班车 / 共享单车 / 打车排队第 7 位 / 高铁改签 / 航班延误 / 地铁坐过站 / 导航说"已偏航"

**消费**：外卖 / 快递柜取件码 / 购物车没结算 / 便利店关东煮 / 扫码支付失败 / 会员到期提醒

**设备**：电量 12% / 低电量模式 / AirPods 只剩一只 / 屏幕使用时间周报 / 耳机线绕两圈 / 充电宝没还

**居家**：洗衣机还在转 / 外卖盒没扔 / 冰箱贴 / 门禁卡 / 晾了三天的衣服 / 备用钥匙

**数字**：验证码 / 云相册"去年今日" / 聊天记录 / 收藏夹 / 共同歌单 / 共享相册

**English**：2am laundromat / Netflix password still saved / read receipt / last seen 3 months ago /
screen time report / "on my way" typed and unsent / half-empty fridge / shared playlist /
airpods case / food delivery note / package locker code / 12% battery
