## Multi-syllabic Rhyme Starters

Multi-syllabic rhyme reads as high craft. Build it by locking 2+ syllables:

| Pattern | Pairs |
| --- | --- |
| 2-syl (-ation) | mo**tiva**tion / ele**va**tion / obser**va**tion / o**ver**-re**ac**tion |
| 2-syl (-ity) | real**ity** / fatal**ity** / electr**ic**-**ity** / since**rity** |
| 2-syl (-ical) | mus**ical** / crit**ical** / typ**ical** / iron**ical** |
| 2-syl (-ember) | re**mem**ber / De**cem**ber / dis**mem**ber / em**ber** |
| 3-syl (-enery) | ma**chin**ery / scen**ery** / gre**enery** |
| 3-syl (-imilar) | s**imilar** / d**issim**ilar |

| Mood | Families |
| --- | --- |
| Warm / open | -ay, -ow, -ame, -ain |
| Dark / closed | -ight, -ong, -ell, -uck |
| Driving / rap | -ing, -end, -ame, -ound |
| Tender / soft | -een, -ine, -ow |
| Anthemic | -art, -all, -ame, -ound |

## Antidote List — Overused Rhymes

These pairings are so common they read as filler. Flag and avoid:

- fire / desire
- love / above
- night / light
- heart / apart
- time / mind
- rain / pain
- alone / home / phone
- true / you
- free / be / me
- day / away

**Fix**: switch family entirely, or use a slant rhyme from a different family on one line to break the pattern.
