# 歌词诊断表

> **这不是门槛，没有及格线。** 这里描述的是"好歌词长什么样"，
> 用途只有一个：**你已经觉得"哪里不对但说不上来"的时候，用来定位。**
> 写顺了就别看；把它当条件去凑，就会去凑条件而不是写好歌。
>
> 真门槛只有 `AGENTS.md` 第 4 节那 11 条。

---

## 一、怀疑"不成篇"

- [ ] **有一条走向**：全首的情绪或处境要移动（⚠️ 场景变化 ≠ 情感变化）。
      **不一定是故事**——视线一路往下、同一个念头越想越深，都算
- [ ] **句间有东西连着**：抽 3 处相邻句，能说出凭什么挨在一起——因果 / 递进 / 转折 / 对比，
      **或者并置**（同一个场景的侧面、同一个物件的两个状态）。
      ⚠️ **并置不算流水账**；六件事互不相关、连一条线都没有，才算
- [ ] **副歌的必然性**：副歌是从主歌"逼"出来的，不是换个话题再写一段
- [ ] **段末落在某处**：可以比首句更远，也可以只是收住
- [ ] **有一个物件出现 ≥ 2 次且状态发生了变化**（线索物，不是装饰）

## 二、怀疑"不像歌词""太散"

- [ ] **这句在说一个处境，还是在讲两件先后发生的事** —— 先后（于是/结果）是情节，听的人在等下一句；
      ⚠️ **不要数代词和动作**：`我送你离开 千里之外` 两个施动者、`越过山丘 虽然已白了头` 一个人两件事，
      都是好词。数量定不了这个（`lyric-zh` 第五节）
- [ ] 副歌韵辙统一；押韵密度对着 `lyric-zh` 第二节的表看
- [ ] **重韵按听感判**：相邻两句同字要改；一段内同一个字 ≥3 次要改；
      隔开且刻意的呼应（副歌首尾、hook 复沓）**不算重韵，别改**
- [ ] 同段落对应句字数大体齐——**差一两个字最舒服，差到一半就装不回去**；**hook 和段末落句除外**，它们本来就该短/长
- [ ] **拗口自查**（别写"念一遍顺口"——你读不出声）：连续同声母字、连续同韵母字、
      一句超一口气；无文言倒装、无"为押韵而押韵"的废句
- [ ] **无倒字**：句尾 / hook / 长音位**优先平声、避开上声**（去声视旋律定，有 demo 才查）；无连续两个三声；一句内无 ≥3 个同声母字
- [ ] **hook 基本满足**：在副歌首句、开口元音、字面重复 2–3 次、就是歌名；
      长度通常短于周边句（也可以是最长那句，只要最好记）
- [ ] **后出的主歌推进了一层**（换时间 / 换观察对象 / 物件变化），不是换个说法重复
- [ ] 主歌**具体**、副歌**普世**、桥段换视角

## 三、怀疑"太 AI 了"

- [ ] 每段有能被镜头拍到的细节，**但不数个数**（凑数就会写成报菜名）；抽象情绪词很少
- [ ] **细节有东西串着**（视线 / 动作 / 同一个物件），不是一行一件的分镜表
- [ ] 通用意象的限定来自 ⓪ 那个场景里真实存在的东西，**不是加形容词**（"温柔的月光"不算限定）
- [ ] **有一句"只有这个人会说"的话**

> 最后一项是**优先级最高的信号**——它不是说"不合格"，而是说"这里最值得改"。

## 四、怀疑"结构不对"

- [ ] **不是每段都 4 句** —— 但句数是数出来的，不是照着表定的
- [ ] **副歌没吃掉整首歌**：副歌次数 ≤ 4（只有这一半是硬的）。相邻两次副歌完全一样也成立——
      差异交给演唱与编曲；**不要为了"有变化"去改一句本来更好的词**
- [ ] 副歌 ≥ 3 次时，有一处爬升或留白（Pre-Chorus / 器乐段 / 抽空），不是副歌连着砸
- [ ] 骨架理由与实际结构一致：说"末次加长"就真的加长了

## 五、症状 → 处方（卡住时对号入座）

| 症状 | 处方 |
| --- | --- |
| 唱着别扭 | 查连续同声母 / 同韵母字、一句超一口气、比较句与条件句没有断点，**不是改词藻** |
| 文言倒装 | "繁花落尽处"式生硬 → 改成口语能说的话："花都落完了" |
| 抽象词堆叠 | 孤独、寂寞、忧伤连用 → 换成具象：空椅子、未接来电、凉掉的茶 |
| 韵脚陈词 | 心 / 人 / 情 / 梦 / 痛 反复出现 → 换辙，或去 `rhyme-zh.md` 找同辙冷门字 |
| 韵脚平淡 | 换韵辙，或改用句中韵 / 仄声韵 |
| 字数失控 | 一句 5 字一句 14 字 → 按"一口气唱完"拆句或删字 |
| 没有画面 | 走 `lyric-imagery-rhyme` 补具象，替换抽象形容词 |
| 副歌不抓耳 | 缩短句子、提高重复密度、把 hook 挪到句首 |
| 副歌无 hook | 每句都新，没有重复 → 把核心句提到句首并重复 2–3 次 |
| 情绪不到位 | 动的是意象的**温度**（冷/暖、动/静），不是加形容词 |
| 人称混乱 | 一段"我"一段"你"一段"他" → 通篇统一，桥段才允许切换 |
| 整首绵软 | 多用平声 / 弱韵 → 换仄声韵或更硬的辙（江阳、中东） |
